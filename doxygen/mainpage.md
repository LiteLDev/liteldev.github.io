# C++ Reference

The C++ API of LeviLamina, generated from its headers: LeviLamina's own API in the `ll` namespace, and the %Minecraft Bedrock Dedicated Server and client classes it exposes (in the global namespace and `mce`, `Bedrock`, …). New to modding? Start with the tutorial [Your first LeviLamina mod](/tutorials/develop/first-levilamina-mod/); the [API guides](/LeviLamina/api_reference/) explain each part of the API with examples.

## Browse

- [Namespaces](namespaces.html): every namespace, starting with `ll`, LeviLamina's API.
- [Class List](annotated.html) and the [Class Index](classes.html) (A–Z): every class, struct, and union.
- [Class Hierarchy](hierarchy.html): classes organized by inheritance.
- [Class Members](functions.html): every function, variable, type, and enum value, by name.
- [File List](files.html): the headers, as laid out in the repository.

## Find something

Press <kbd>Ctrl</kbd> <kbd>K</kbd> (or <kbd>/</kbd>) to search the reference by name for classes, functions, variables, types, and files. The tree on the left lists the same pages; on phones, it is in the menu.

## Where it comes from

This reference is built from the `src/`, `src-server/`, and `src-client/` headers of the [LeviLamina repository](https://github.com/LiteLDev/LeviLamina)'s default branch within an hour of each change. Functions marked *not yet publicly available* are part of %Minecraft, but are not yet exported to mods; their documentation explains how to request access.
