# lip daemon

显示或停止 lip 的守护进程。

## 概要

```
lip daemon status [--json] [-h | --help]
lip daemon stop [-h | --help]
```

## 说明

**守护进程**是在你当前用户下后台运行的 `lip` 进程，负责替其他所有 `lip` 进程执行命令（包括除 `daemon` 组以外的所有命令以及界面操作）。[托管服务器](run.md#托管服务器)也由它运行。

你不需要自己启动它：

1. 命令会连接守护进程。如果没有守护进程在监听，命令会使用自身的环境变量启动一个，并将其与终端分离。
2. 如果守护进程属于另一个 lip 版本或另一个 `lip` 可执行文件，命令会要求它退出，再启动一个新的。忙碌中的守护进程会继续运行；参见[更新之后](#更新之后)。
3. 守护进程执行命令的方式与你直接启动的 `lip` 完全一样：在你的工作目录中运行，使用你的环境变量，读取你的标准输入，写入你的标准输出和标准错误，并接收你按下的 Ctrl+C。`lip` 会以该命令的退出码退出。

如果无法启动或连接守护进程，命令会输出一条消息，然后自己执行。此时只有 `lip run --managed` 会失败。

守护进程替两个终端执行的两条命令，表现得就像两个独立的进程：例如，一条命令持有工作区锁时，另一条命令会发现锁已被占用。

守护进程会在以下情况下自行退出：

- 一段时间内既没有连接，也没有运行托管服务器（当前版本中为 10 分钟）；
- 更新版本的或另一个 `lip` 要求它退出，且它正处于空闲状态；
- 执行 [`lip self-update`](self_update.md) 并实际更新了 lip 或启动了安装程序之后，一旦进入空闲状态。

守护进程通过仅限当前用户使用的端点进行访问：Windows 上是命名管道，其他系统上是 Unix 套接字。参见[守护进程端点](../files.md#守护进程端点)。

### lip daemon status

显示是否有守护进程在端点上监听；如果有，还会显示它的版本和进程 ID。

### lip daemon stop

要求守护进程退出，并等待它退出。

- 没有守护进程在监听时，命令直接成功，不做任何更改。
- 守护进程正在执行命令或运行托管服务器时，**命令失败，守护进程继续运行**。请先停止托管服务器（在各个工作区中用 `lip run --managed` 连接并按 Ctrl+C，或在界面的服务器页停止），并等待其他命令结束，然后再次运行 `lip daemon stop`。

这两条命令都由你启动的进程自己执行，从不交给守护进程，也从不启动守护进程。

### 更新之后

旧版本 lip 的守护进程如果仍在运行托管服务器或执行命令，就不会被替换。在它进入空闲状态之前：

- `lip run --managed` 会使用旧的守护进程，因此你仍然可以连接并停止它的服务器；
- 其他命令会输出一条消息，然后由新的 `lip` 自己执行。

停止托管服务器之后，下一条命令就会启动新版本的守护进程。

## 选项

| 选项 | 说明 |
| --- | --- |
| `--json` | 用于 `status`：以 JSON 格式输出结果。 |
| `-h`、`--help` | 输出帮助信息并退出。 |

## 输出

`lip daemon status` 会将结果写入标准输出。不带 `--json` 时，输出便于阅读的单行文本：

```
The daemon of lip does not run.
```

```
The daemon of lip 1.0.0 runs as process 4812, carrying out 0 commands.
```

带 `--json` 时，如果没有守护进程在监听：

```json
{"running":false}
```

如果有守护进程在监听：

```json
{"running":true,"version":"1.0.0","pid":4812}
```

| 成员 | 值 |
| --- | --- |
| `running` | 布尔值：是否有守护进程在端点上监听。 |
| `version` | 字符串：守护进程的版本，即其 `lip -v` 输出的内容。仅当 `running` 为 `true` 时存在。 |
| `pid` | 数字：守护进程的进程 ID。仅当 `running` 为 `true` 时存在。 |

`lip daemon stop` 没有输出结果；它会将消息写入标准错误。

## 退出状态

| 命令 | `0` | 非 `0` |
| --- | --- | --- |
| `lip daemon status` | 无论守护进程是否在运行。 | 用法错误。 |
| `lip daemon stop` | 守护进程已退出，或本来就没有运行。 | 用法错误，或守护进程因正忙而继续运行。 |

## 示例

查看守护进程是否在运行：

```shell
lip daemon status
```

在脚本中，仅当守护进程在运行时停止它：

```shell
lip daemon status --json | jq -e '.running' > /dev/null && lip daemon stop
```
