# 服务器

服务器页面用来在当前工作区安装服务器，同时也是服务器的控制台。读完这一页，你就能安装服务器、更改游戏或加载器版本、启动和停止服务器、查看输出、发送命令、设置崩溃后自动重启，并了解退出 lip 时服务器会怎样。

如果你还不熟悉按键和界面各部分，请先阅读[界面导览](./tour.md)。

## 页面的组成

![服务器运行期间的服务器页面。编号标出状态行、输出区和输入行。](/screenshots/zh-Hans/server-02-running.svg)

1. **状态行**说明服务器是否在运行。下方是**启动**或**停止**按钮、**自动重启**选项，以及**更改版本…**按钮。
2. **输出区**显示服务器的输出内容。
3. **输入行**用来向服务器发送命令。只有服务器运行时才会出现这一行。

按 `Tab` 依次在按钮和选项、输出区、输入行之间切换。按 `←` 和 `→` 在按钮和选项之间移动。

## 服务器的每种状态

状态行始终显示以下状态之一。

### 这里还没有服务器

没有安装游戏的文件夹里没有可运行的内容，页面上只有一个按钮。

![空文件夹的服务器页面。写着“这里还没有服务器。”，有一个“安装服务器…”按钮，下面一行是“在此工作区中安装游戏版本和加载器。”](/screenshots/zh-Hans/server-03-no-server.svg)

按 `Enter` 在当前工作区安装服务器。各步骤的说明见[安装服务器](#安装服务器)。

### 未运行

`○ 未运行`表示服务器当前没有运行，而且自 lip 启动以来也没有运行过。此时输出区为空。

![未运行的服务器的服务器页面。“启动”按钮处于高亮，输出区写着“还没有输出。”](/screenshots/zh-Hans/server-01-stopped.svg)

选中**启动**并按 `Enter` 即可启动服务器。

### 运行中

按下“启动”后，在服务器程序真正跑起来之前，状态会显示为 `●` **正在启动**。这通常只持续一瞬间。如果 lip 首次运行需要为服务器准备系统环境（例如 Windows 上的 Visual C++ 运行库，或 Linux 和 macOS 上的 Wine），耗时就会长一些。如果这一步失败，lip 会显示失败原因，状态回到 `○` **未运行**。

随后状态变为 `●` **运行中**。只要服务器程序启动，哪怕还在加载世界和模组，状态都算作运行中。

![刚按下“启动”的服务器页面。状态是“运行中 · 00:00:00”，按钮变成“停止”，输出区有一行灰色文字，输入行出现了。](/screenshots/zh-Hans/server-05-just-started.svg)

1. `● 运行中`，后面跟着服务器已运行的时间（时:分:秒）。
2. 按钮变为**停止**。
3. 两端带横线的灰色提示行由 lip 生成，不是服务器的输出。
4. 输入行出现，焦点自动移到这里。

此时 lip 顶栏也会显示 `● 运行中`，侧边栏的“服务器”后面会多出一个 `●`。即使切换到其他页面，服务器也会在后台继续运行。

当服务器输出 `Server started.` 时，玩家就可以进服了。

::: info
如果服务器根本无法启动（例如缺少游戏文件），lip 会弹出出错对话框，状态保持为“未运行”。详见[出错的时候](./tour.md#出错的时候)。
:::

### 正在停止

发出停止指令后，在服务器彻底退出前，状态会显示为 `● 正在停止`。服务器通常需要几秒钟来保存世界。

![按下 Ctrl+C 之后的服务器页面。状态是“正在停止”，输出区有一行灰色的“asking the server to stop”。](/screenshots/zh-Hans/server-08-stopping.svg)

1. lip 已请求服务器停止，正在等待它退出。
2. lip 向服务器发送了 `stop` 命令。

在此期间，“停止”按钮呈灰色，再按一次也不会有额外效果。

### 已退出，带退出码

服务器退出后，状态变为 `○ 已退出，退出码`加一个数字。退出码 `0` 表示正常退出，其他数字表示出了问题。

![已结束的服务器的服务器页面。状态是“已退出，退出码 0”，按钮又变回“启动”，输出还在。](/screenshots/zh-Hans/server-09-exited.svg)

1. 服务器已停止运行。
2. 按**启动**可以重新启动服务器。
3. 输出内容会保留下来，方便你排查服务器退出的原因。

### 正在重启

如果服务器并非由你主动停止，而是以非 `0` 退出码结束，且已开启**自动重启**，lip 会在 5 秒后重新启动它。这期间状态显示为 `● 正在重启`，后面附上退出码。

![崩溃之后的服务器页面。状态是“正在重启 · 已退出，退出码 -1073741819”，自动重启已勾选，lip 用一行黄色文字说明 5 秒后重新启动服务器。](/screenshots/zh-Hans/server-11-restarting.svg)

1. lip 等待片刻后重新启动服务器。
2. 服务器退出的方式。
3. 自动重启已开启。

在等待期间按 `Ctrl+C` 或**停止**，即可取消重启。

### 在此界面之外运行

服务器也可以在另一个终端里用普通的 `lip run` 命令启动。这时 lip 只知道服务器正在运行，无法获取其他信息。

![服务器页面写着“在此界面之外运行”。按钮下方有一行“它由另一个 `lip run` 启动，请在那里停止。”](/screenshots/zh-Hans/server-10-elsewhere.svg)

1. 服务器正在运行，但不是从当前界面启动的。
2. **启动**按钮不可用，也没有“停止”按钮。
3. 请回到启动它的终端去停止服务器。

此时页面上没有输出区和输入行，因为它们归启动服务器的那个终端所有。不过，与“服务器正在运行”相关的其他限制依然生效：在服务器停止前不能改动模组。

## 安装服务器

**安装服务器…**会在当前工作区安装服务器，包括游戏本体，以及运行模组所需的 LeviLamina。lip 会通过一系列对话框向你确认几个选项，然后开始安装。按 `Esc` 可返回上一步；在第一步按 `Esc` 则会直接关闭对话框，不做任何改动。

从[主页](home.md)的第 2 步也会进入这个流程。[开你的第一个服务器](https://levimc.org/zh-Hans/tutorials/server/first-server/)带你完整走了一遍流程；本节详细说明其中的每一个选项。

### 服务器放在哪里

服务器会安装到当前工作区，即顶栏显示的文件夹。

![没有服务器的文件夹的服务器页面。“安装服务器…”按钮被标出，下面一行写着“在此工作区中安装游戏版本和加载器。”](/screenshots/zh-Hans/new-server-01-where.svg)

1. 服务器会安装到顶栏所示的当前工作区。

如果想把服务器装到其他文件夹，请先在[工作区选择器](workspaces.md)里选中目标文件夹（可以选择已有文件夹，或用**添加文件夹…**新建一个），然后回到本页面，在**安装服务器…**上按 `Enter`。

### 第 1 步：游戏版本

lip 会获取可下载的游戏版本（需要一点时间）并列出：先按从新到旧的顺序排列正式版，随后是标有**预览版**的预览版本。

![“游戏版本”对话框列出 1.26.60 到 1.21.130。大多数行显示“LeviLamina ✓”，第一行标着“最新”。](/screenshots/zh-Hans/new-server-04-game-version.svg)

版本号后面的一栏说明该版本能否安装模组：

![同一个列表，选中的是显示“无 LeviLamina”的 1.26.30。下面一行写着“模组需要 LeviLamina，而此版本没有。”](/screenshots/zh-Hans/new-server-12-no-levilamina.svg)

1. **LeviLamina ✓**：有支持此版本的 LeviLamina。如果要装模组，请选带有此标记的版本。
2. **无 LeviLamina**：没有适配此版本的 LeviLamina。这类版本只能作为纯净服务器运行。
3. 当前选中行的文字说明。

::: info 这一栏为什么重要
模组不能直接在游戏上运行。它们依赖加载器 **LeviLamina**，而每个 LeviLamina 版本只对应一个游戏版本。最新的游戏版本不一定已经有对应的 LeviLamina。
:::

这一栏的信息来自 levimc.org 的模组目录。如果目录在几秒钟内没有响应，列表就不会显示这一栏；但到选择加载器那一步时，依然会告诉你有哪些可用版本。

用 `↑` `↓` 选择版本，然后按 `Enter`。

### 第 2 步：构建（仅限 x64 的 Linux）

游戏有两种**构建**：Windows 服务器和 Linux 服务器。LeviLamina 及其模组需要 Windows 服务器。

只有在两种构建都能运行的系统上（即 x64 处理器上的 Linux），且所选游戏版本同时提供这两种构建时，lip 才会询问构建类型。其他情况下构建固定为 `windows`，你不会看到这一步。在 Linux 上，如果某个版本只提供一种构建，版本列表中会直接注明：

![Linux 上的游戏版本列表。1.26.30 一行在“无 LeviLamina”后面标着“仅 windows”。](/screenshots/zh-Hans/new-server-16-linux-games.svg)

1. 没有提供 Linux 服务器的版本：选中它时，lip 不会询问构建类型。

![“构建”对话框有 windows 和 linux 两行。选中的是 linux，下面一行写着“没有加载器；仅适用于 x64 的 Linux。”](/screenshots/zh-Hans/new-server-17-build.svg)

1. **windows**：Windows 服务器，lip 通过 Wine 运行它。只有它支持 LeviLamina 及其模组。
2. **linux**：Linux 服务器。无需 Wine，没有加载器，也不能运行模组。选中后 lip 会跳过加载器这一步。

关于 Wine 和 Linux 服务器的详情，见 [Linux 与 macOS](../guides/linux_macos.md)。

### 第 3 步：加载器

lip 会查找适配所选游戏版本的 LeviLamina 版本（可能需要一点时间），并按从新到旧的顺序列出，最后一项是**不安装加载器**。

![“加载器”对话框列出标着“最新”的 LeviLamina 26.60.3 到 26.60.0，然后是“不安装加载器”。下面一行写着“让服务器可以运行模组。”](/screenshots/zh-Hans/new-server-05-loader.svg)

如果要安装模组，请在第一行（最新的 LeviLamina）上按 `Enter`。

选择**不安装加载器**则只安装游戏本体，即不能运行模组的纯净服务器。

![同一个对话框，选中的是“不安装加载器”。下面一行写着“纯净服务器，不带模组。”](/screenshots/zh-Hans/new-server-14-no-loader.svg)

如果没有适配该游戏版本的 LeviLamina，这一步会给出说明，并提供后续选项：

![“加载器”对话框以“没有支持此游戏版本的 LeviLamina。”开头，有“不安装加载器”和“返回”两行。](/screenshots/zh-Hans/new-server-13-no-loader-fits.svg)

1. **不安装加载器**：继续安装纯净服务器。
2. **返回**：退回游戏版本列表，以便改选带有 **LeviLamina ✓** 的版本。按 `Esc` 效果相同。

### 第 4 步：计划

lip 会先显示将要安装的内容，此时还没有安装任何东西。

![“安装服务器”对话框列出三行以“Dry run:”开头的内容，有“应用”和“取消”两个按钮。](/screenshots/zh-Hans/new-server-06-plan.svg)

这几行直接来自命令的英文输出：将安装游戏和 LeviLamina，并且 lip 会请你接受许可协议。

- **应用**：开始安装。
- **取消**：什么也不安装，页面上仍然是**安装服务器…**。

### 第 5 步：许可协议

游戏归 Microsoft 所有。在 lip 下载它之前，你必须接受《Minecraft 最终用户许可协议》和《Microsoft 隐私政策》。请访问对话框中显示的两个网址阅读协议。

![“Minecraft EULA”对话框写出两份文件的名称和网址，有“接受”和“拒绝”两个按钮。](/screenshots/zh-Hans/new-server-07-eula.svg)

选择**接受**继续安装；选择**拒绝**则不会安装任何东西：

![同一个对话框，“拒绝”按钮被标出。](/screenshots/zh-Hans/new-server-15-eula-decline.svg)

工作区保持原样，页面上依然显示**安装服务器…**。

![拒绝之后的服务器页面：“这里还没有服务器。”和被标出的“安装服务器…”按钮。](/screenshots/zh-Hans/new-server-18-not-set-up.svg)

### 第 6 步：下载与结果

lip 开始下载并安装游戏和 LeviLamina。按 `Esc` 可取消安装，已完成的部分会被撤销。

![“安装服务器”对话框显示两项下载，一项是 100%，另一项是 62%。](/screenshots/zh-Hans/new-server-08-progress.svg)

安装完成后，对话框会列出已安装的内容，最后一行显示 **✓ 完成。** 按 `Enter` 确认。

![“安装服务器”对话框列出已安装的两个包，最后是“完成。”和“确定”按钮。](/screenshots/zh-Hans/new-server-09-result.svg)

现在页面上会显示这个服务器，状态为未运行，随时可以启动。

![服务器页面，状态是“未运行”，有“启动”和“更改版本…”按钮，以及“自动重启”选项。“启动”被标出。](/screenshots/zh-Hans/new-server-10-workspace.svg)

1. **更改版本…**：用其他版本重新安装服务器。

在**启动**上按 `Enter` 即可启动服务器，你也可以先去[市场](get_mods.md)。

::: details 用命令做同样的事
这一过程会在当前工作区中根据你的选择执行 [`lip setup`](../reference/commands/setup.md)，例如：

```shell
lip setup --game 1.26.60 --loader levilamina@26.60.3
```

选择**不安装加载器**对应 `--no-loader`，选择 Linux 服务器对应 `--build linux`。
:::

## 更改游戏或加载器的版本

要更换服务器的游戏版本或 LeviLamina 版本，请使用**更改版本…**重新安装。步骤与[安装服务器](#安装服务器)相同，只是每一步都默认选中服务器当前的版本。

1. 按两次 `→`，从**启动**移到**更改版本…**，旁边会显示**更换游戏或加载器。** 按 `Enter`。

   ![未运行的服务器的服务器页面。“更改版本…”按钮被标出，后面一句是“更换游戏或加载器。”](/screenshots/zh-Hans/workspaces-14-change-button.svg)

2. 选择游戏版本。服务器当前的版本标有**已安装**，并处于默认选中状态。

   ![“游戏版本”对话框，选中的 1.26.60 标着“最新”和“已安装”。](/screenshots/zh-Hans/workspaces-14-change-game-version.svg)

3. 选择加载器。对话框默认选中服务器当前的 LeviLamina 版本；如果未安装加载器，则默认选中**不安装加载器**。

   ![“加载器”对话框，选中的是最新版本下面一行的 LeviLamina 26.60.2。](/screenshots/zh-Hans/workspaces-15-change-loader.svg)

4. 查看计划，然后选择**应用**。

   ![“安装服务器”对话框写着 lip 将卸载 LeviLamina 26.60.3 并安装 LeviLamina 26.60.2，有“应用”和“取消”两个按钮。](/screenshots/zh-Hans/workspaces-16-change-plan.svg)

   1. lip 将要移除和安装的内容（命令的原始输出）。
   2. 选择**应用**之前不会执行任何更改。

服务器运行期间，**更改版本…**呈灰色不可用状态，移到上面会提示**请先停止服务器。** lip 不会在服务器运行时更换游戏。

::: warning 不适合新版本的模组
模组是针对特定 LeviLamina 版本制作的。如果某个已安装的模组没有兼容所选游戏或 LeviLamina 的版本，计划中会列出该模组，并说明本次安装将卸载它。此时选择**应用**就会卸载这些模组。如果想保持原样，请选择**取消**。
:::

如果你选择的就是服务器当前的版本，则无需执行任何操作，计划中只有**关闭**按钮：

![“安装服务器”对话框写着“不会有任何更改。”，只有“关闭”一个按钮。](/screenshots/zh-Hans/plan-02-no-changes.svg)

更换游戏版本会保留 `server.properties`、`allowlist.json`、`permissions.json` 以及你的存档。旧版游戏的其他文件会被删除，你复制到 `behavior_packs/` 或 `resource_packs/` 中的资源包也会一并删除；完整清单请参见[更换游戏后保留什么](../reference/files.md#更换游戏后保留什么)。建议先备份文件夹，因为旧版本游戏可能无法打开新版本保存的存档。

### 在别的系统上打开使用 Linux 构建的服务器

安装为 Linux 服务器的工作区只能在 x64 Linux 上运行。在其他系统上，lip 无法提供该构建，因此会在你做出任何选择前先行说明，然后改按 Windows 服务器继续：

![“游戏版本”对话框开头有两行：“此工作区使用 linux 构建，它无法在本系统上运行。安装时会改用 windows 构建。”](/screenshots/zh-Hans/workspaces-17-linux-build.svg)

1. 提示信息，在你做出任何选择前就会显示。

随后，计划的标题会写明**改用 windows 构建**，并将 Linux 服务器列在待卸载内容中：

![“改用 windows 构建”对话框列出 lip 将卸载 Linux 版游戏，并安装 Windows 版游戏和 LeviLamina。](/screenshots/zh-Hans/workspaces-18-switch-to-windows.svg)

## 启动和停止

在**启动**上按 `Enter` 即可启动服务器。[主页](./home.md)的第 4 步执行的是同一操作。

停止服务器有两种方法：

- 在服务器页面的任意位置按 `Ctrl+C`；或者
- 按 `Tab` 切换到**停止**并按 `Enter`。

这两种方法都会向服务器发送 `stop` 命令，让它在保存世界后自行退出。lip 绝不会强制终止服务器进程。

::: warning
在其他页面上，按 `Ctrl+C` 会询问是否退出 lip。只有在服务器页面且服务器正在运行时，它才会停止服务器。
:::

## 查看输出

当焦点位于输入行时，输出区会随服务器输出自动滚动，新内容显示在底部。

要向上翻看历史输出，请在输入行按 `Esc`。焦点会移至输出区，其标题随之高亮。

![输出区拥有焦点，并且已向上滚动。右边缘的标记表示上下还有内容。](/screenshots/zh-Hans/server-06-output-scrolled.svg)

1. 焦点位于输出区。
2. `▲` 和 `▼` 表示上方和下方还有内容。
3. 用于滚动的按键。

| 按键 | 作用 |
| --- | --- |
| `↑` `↓` | 滚动一行。 |
| `PgUp` `PgDn` | 滚动一屏。 |
| `Home` | 跳到第一行。 |
| `End` | 回到最后一行。 |

向上翻看时，即使服务器继续产生新输出，当前查看的内容也不会滚动。

要回到输入行，请按 `End` 后再按 `↓`，或者直接按 `Tab`。

## 向服务器发送命令

在输入行中输入服务器命令，按 `Enter` 发送。输入行为空时，灰色的 `list` 只是示例占位符，不会被发送。

![输入行里是“say Welcome to Survival”。](/screenshots/zh-Hans/server-02-running.svg)

服务器的响应会显示在输出区中。

lip 会记录你发送过的命令。在输入行按 `↑` 可调出上一条命令，按 `↓` 可向后翻找。当前正在输入的内容不会丢失：按 `↓` 翻过最后一条历史记录后，它就会恢复。

![输入行显示用上方向键调出的“list”。底部一行列出“↑↓ 历史”。](/screenshots/zh-Hans/server-07-history.svg)

这里输入的是 Minecraft 服务器命令（如 `list` 或 `say`），而不是 lip 命令。

### 离开输入行

当焦点位于输入行时，你输入的任何字母都会作为命令输入，因此需要按 `Esc` 离开：

1. 按 `Esc`，从输入行移至输出区。
2. 再按 `Esc`，移至侧边栏。

按 `Tab` 也可以离开输入行，直接跳到侧边栏。

## 自动重启

**自动重启**决定了服务器崩溃后 lip 是否自动重启它。按 `→` 从按钮移至该选项时，右侧会显示一行说明；按 `Space` 切换勾选状态。

![“自动重启”选项已勾选并处于高亮。右边是一句“崩溃后重新启动。”](/screenshots/zh-Hans/server-04-auto-restart.svg)

开启此选项后：

- 如果服务器以非 `0` 退出码结束，lip 会在 5 秒后重新启动它。
- 如果服务器是由你主动停止的，或以退出码 `0` 正常结束，则不会重启。
- 如果在 10 分钟内重启达到 5 次，lip 将停止重启，并在输出区说明情况。此时请向上翻看输出，排查服务器反复崩溃的原因。

该选项保存在工作区中，因此每个服务器都可以独立设置。[设置](./settings.md)页面中显示的是同一个选项。

## 服务器运行时退出

在服务器运行期间退出 lip 时，确认提示会说明服务器的后续状态。

![询问“要退出 lip 吗？”，第二行是“运行中的服务器会继续运行。”](/screenshots/zh-Hans/server-12-quit-keeps-running.svg)

通常情况下，服务器会**继续运行**。lip 会将服务器交由后台程序（守护进程）托管，界面关闭后它仍在后台运行，你也可以直接关闭终端。之后若想重新接管，只需在同一文件夹下打开终端并运行 `lip`：服务器页面会显示该服务器及其最近的输出，你可以像之前一样输入命令或停止服务器。

只有一种罕见的例外情况：当 lip 无法使用守护进程、所有任务都由主程序直接运行时，提示信息会变为：

![询问“要退出 lip 吗？”，第二行是“运行中的服务器会先停止。”](/screenshots/zh-Hans/server-13-quit-stops.svg)

此时如果选择**退出**，lip 会先通知所有运行中的服务器停止，并在等待它们退出的过程中显示服务器页面，待全部停止后再退出程序。

## 托管服务器

在此页面启动的是托管服务器。它由 lip 的守护进程运行，不属于任何终端，因此退出 lip 后仍会继续运行。多个终端可以同时查看同一个服务器，每个工作区也可以各自同时运行一个服务器。`lip run --managed` 命令启动和显示的就是这批服务器。详见[用命令行开服](https://levimc.org/zh-Hans/tutorials/server/command-line/)，其中也介绍了如何在不使用界面时停止服务器。
