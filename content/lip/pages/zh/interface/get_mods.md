# 市场

市场页面就是内置在 lip 里的 [levimc.org](https://levimc.org/mods/) 模组列表。读完这一页，你就能通过搜索、排序和筛选找到模组，了解其详情，并安装与服务器匹配的版本。

如果你还不熟悉按键和屏幕上的各个区域，请先阅读[界面导览](./tour.md)。

## 页面

![市场页面。编号标出搜索、排序、筛选三行，模组列表，以及高亮模组的详情。](/screenshots/zh-Hans/get-mods-01-list.svg)

1. **搜索**、**排序**和**筛选**决定列出哪些模组，以及按什么顺序列出。
2. 模组**列表**。页面打开时焦点在这里。
3. 高亮模组的**详情**。

在第一个模组上按 `↑`，焦点会依次移到筛选、排序和搜索。从这些位置按 `↓`，或者在搜索框里按 `Enter`，即可回到列表。按 `Tab` 也能在这些区域之间循环切换。

lip 管理的是服务器，因此列表里只显示能在服务器上运行的模组。每次打开 lip 时，列表都会从 levimc.org 重新读取，不会保存到磁盘。

## 列表

![已有模组的服务器里的模组列表。编号标出对勾、名称和作者、下载量、星标、日期和数量。](/screenshots/zh-Hans/get-mods-06-columns.svg)

1. `✓` 表示该模组已安装在当前工作区。
2. 模组名称，点号后面是作者。
3. `↓` 是模组的下载次数。`186k` 大约是 18.6 万。
4. `★` 是模组在 GitHub 上的星标数。
5. 最近一次更新的日期。
6. 列表上方的一行显示当前列出了多少个模组。

如果模组没有下载量或星标，对应的一列会留空。终端较窄时，会先隐藏日期，再隐藏下载量。

### 详情

在列表里上下移动时，详情会随之更新。这里先显示模组的简介，随后是：

| 行 | 显示 |
| --- | --- |
| 作者 | 发布模组的人。 |
| 下载量、星标 | 确切的数字。 |
| ID | 模组仓库的地址，也就是它在[模组](./mods.md)页面上的名字。 |
| 最新版本 | 最新的版本；模组有变体时，`#` 后面是变体。 |
| 平台 | 模组支持的系统。 |
| 游戏 | 模组支持的游戏版本。 |
| 标签 | 模组的类型。 |
| 许可证 | 模组的许可证。 |
| 依赖 | 模组所需的依赖项及可接受的版本范围。lip 会自动为你装好。 |
| 更新日期 | 最近一次更新的日期。 |

如果详情内容超出方框高度，右边缘会出现 `▼`。按 `Tab` 将焦点移到详情区，即可滚动查看。

![详情区拥有焦点并已滚动。右边缘的标记表示上下还有内容。](/screenshots/zh-Hans/get-mods-07-details-scroll.svg)

1. 详情区拥有焦点时，标题会高亮显示。
2. `▲` 和 `▼` 表示上方和下方还有内容。
3. 用于滚动的按键。

按 `Esc` 回到列表。

终端宽度达到 106 列左右或更宽时，详情会显示在列表右侧，列表一次能展示更多行：

![宽终端里的市场页面。详情显示在列表右侧。](/screenshots/zh-Hans/get-mods-08-wide.svg)

## 搜索

按 `↑` 直到**搜索**高亮，然后直接输入。每输入一个字符，列表都会实时更新。

![搜索框里输入了“legacy”。列表里是匹配的三个模组。](/screenshots/zh-Hans/get-mods-02-search.svg)

搜索范围涵盖每个模组的名称、作者、简介、标签和许可证。输入多个词时，模组必须同时匹配所有词才会显示。

搜索还支持当前界面语言。标签会按你的语言显示，直接照着界面上的文字搜即可：例如在中文界面下，输入“经济”或 `economy` 都能找到带有“经济”标签的模组。

![搜索框里是“经济”。列表里有一个模组，它的详情里显示“经济”标签。](/screenshots/zh-Hans/get-mods-09-search-language.svg)

按 `Enter` 移到搜索结果中的模组上。清空输入内容即可重新显示所有模组。

如果没有匹配的模组，列表会提示：

![搜索框里是“dynmap”。列表写着“没有匹配的模组。”](/screenshots/zh-Hans/get-mods-10-no-match.svg)

## 排序

按 `↑` 直到**排序**高亮，按 `←` 和 `→` 切换排序方式。

![排序方式是“热度”。一个星标少、下载多的模组排在星标更多的模组前面。](/screenshots/zh-Hans/get-mods-11-sort.svg)

| 排序方式 | 模组的顺序 |
| --- | --- |
| 相关性 | 按 levimc.org 的默认顺序。搜索时，匹配度最高的排在最前。 |
| 热度 | 最受欢迎的排在最前。 |
| 最近更新 | 最近更新的排在最前。 |
| 最新发布 | 最近发布的排在最前。 |

**热度**由 lip 综合模组的星标数和下载量计算得出，算法与 levimc.org 相同。两项指标权重各占一半，且都是与列表中的其他模组相对比较得出的。因此，热度排序既不完全等同于星标排序，也不完全等同于下载量排序：如图中，星标 61、下载量 17.1 万的模组，就排在星标 152、下载量 6.4 万的模组前面。

## 筛选

筛选可将列表范围缩小到包含（或不包含）特定特征的模组。

1. 按 `↑` 直到**筛选**高亮，然后按 `Enter`。

   ![“筛选”一行处于高亮，它的值是“无”。](/screenshots/zh-Hans/get-mods-12-filters-row.svg)

2. 打开筛选面板。各个分类默认处于收起状态。

   ![筛选面板：“清除筛选”，然后是游戏版本、标签、许可证和依赖于四个分类，每个后面有一个数字。](/screenshots/zh-Hans/get-mods-13-filter-sections.svg)

   1. **清除筛选**会移除所有筛选条件。
   2. 各个分类。后面的数字表示该分类下有多少个选项。
   3. 筛选后剩余的模组数量。面板背后的列表会实时同步变化。

3. 在分类上按 `Enter` 展开或收起，在选项上按 `Space` 切换选中状态。

   ![“标签”分类已展开。一个标签标着 [+]，另一个标着 [-]，面板底部写着“排除”和“3 个模组”。](/screenshots/zh-Hans/get-mods-14-filter-exclude.svg)

   1. `[+]` **包含**：只列出带有该选项的模组。
   2. `[-]` **排除**：不列出带有该选项的模组。
   3. 当前高亮选项的文字状态说明。

4. 按 `Esc` 关闭面板。“筛选”一行会显示当前生效的条件数量。

   ![“筛选”一行写着“已选 1 项”，列表里有两个模组。](/screenshots/zh-Hans/get-mods-16-filters-active.svg)

按 `Space` 可在几种状态间循环切换：未选、包含，以及排除（如果该分类支持）。

| 分类 | 筛选依据 | 包含 | 排除 |
| --- | --- | --- | --- |
| 游戏版本 | 模组支持的游戏版本。 | 可以 | 不可以 |
| 标签 | 模组的类型。常用标签排在前面，按你的语言显示。 | 可以 | 可以 |
| 许可证 | 许可证的类别：宽松许可、弱 Copyleft、Copyleft、其他、无许可证。 | 可以 | 不可以 |
| 依赖于 | 模组所需的依赖项，例如某个库。 | 可以 | 可以 |

选项右侧的数字表示符合该选项的模组数量。

![“许可证”和“依赖于”两个分类已展开。“LegacyRemoteCall”被包含，剩下两个模组。](/screenshots/zh-Hans/get-mods-15-filter-depends.svg)

1. “许可证”下列出的是许可证类别，而非具体许可证名称。
2. 只列出依赖 LegacyRemoteCall 的模组。
3. 筛选后还剩两个模组。

筛选条件会一直保留，直到你手动清除或退出 lip，且会与搜索同时生效。

## 模组的菜单

在模组上按 `Enter` 打开操作菜单。

![一个模组的菜单：安装…、README、在浏览器中打开。](/screenshots/zh-Hans/get-mods-04-menu.svg)

| 操作 | 作用 |
| --- | --- |
| 安装… | 选择版本并安装模组。 |
| README | 显示作者为模组编写的说明文档。 |
| 在浏览器中打开 | 在网页浏览器中打开该模组在 levimc.org 上的页面。 |

### README

README 会在全屏窗口中打开。使用方向键、`PgUp` 和 `PgDn` 滚动查看，按 `Esc` 或 `Enter` 关闭。

![一个模组的 README，显示在占满屏幕的窗口里。](/screenshots/zh-Hans/get-mods-17-readme.svg)

README 会按作者编写的原样以纯文本显示。如果模组没有 README，则会显示“没有 README。”

### 在浏览器中打开

![模组的菜单，“在浏览器中打开”处于高亮。](/screenshots/zh-Hans/get-mods-18-open-in-browser.svg)

lip 会调用系统浏览器打开该页面。在没有桌面环境的服务器上，此操作可能没有任何反应，此时可通过 README 了解模组。如果模组没有对应页面，该选项会呈灰色不可用状态，并提示“此模组没有页面。”

## 安装模组

安装前必须先选择版本。lip 只会列出与当前服务器匹配的版本，因此不必担心选错。

1. 高亮要安装的模组，按 `Enter`，选择**安装…**。
2. 选择版本。匹配的最新版默认已高亮，通常直接按 `Enter` 即可。

   ![LegacyMoney 的版本：0.16.1 和 0.16.0，然后是“自定义…”。最后一行显示将要安装的模组和版本。](/screenshots/zh-Hans/get-mods-25-versions-simple.svg)

   1. 匹配的版本，按从新到旧排列，每个版本后面带有发布日期。
   2. 按 `Enter` 后 lip 即将安装的内容。

3. 检查执行计划。计划中会列出该模组及其所需的其他依赖模组。

   ![计划：“would install LegacyRemoteCall 0.13.0”和“would install LegacyMoney 0.16.1”。](/screenshots/zh-Hans/get-mods-26-install-plan.svg)

   1. LegacyMoney 依赖的模组，lip 会一并安装。
   2. 选择**应用**安装这两个模组，选择**取消**则不进行任何安装。

4. 选择**应用**。执行完毕后，lip 会显示具体操作结果。

   ![结果：两行以“Installing”开头的文字，然后是“✓ 完成。”](/screenshots/zh-Hans/get-mods-27-install-result.svg)

5. 按 `Enter` 返回。该模组及一并安装的依赖模组旁都会标上 `✓`。

   ![安装之后的列表。LegacyMoney 和 LegacyRemoteCall 前面有对勾。](/screenshots/zh-Hans/get-mods-28-installed.svg)

新安装的模组会在服务器下次启动时加载。关于执行计划、进度显示以及出错处理，请参阅[先预览再应用](./tour.md#先预览再应用)。

## 选择版本

### 变体

有些模组有多个变体，即同一个模组针对不同用途的构建，显示为对话框顶部的标签页。按 `←` 和 `→` 切换变体，下面的版本也会跟着变。

![LegacyScriptEngine 的版本。标签页是 lua、quickjs、nodejs 和 python，选中的是 quickjs。](/screenshots/zh-Hans/get-mods-05-versions.svg)

1. 各个变体。选中的在方括号里。
2. 所选变体中与服务器相配的版本。
3. lip 将安装的内容：模组、`#` 加变体、`@` 加版本。

该选哪个变体，请参阅模组的 README。只有一个变体的模组没有标签页。

变体多到一行放不下时，标签页会随着光标移动左右滚动。两端的 `‹` 和 `›` 表示那一侧还有变体。

![一个有十个变体的模组。标签页一行只显示其中一部分，左端有“‹”，右端有“›”。](/screenshots/zh-Hans/get-mods-23-variants-overflow.svg)

1. 左边还有变体。
2. 当前选中的变体。
3. 右边还有变体。

### 只列出相配的版本

列表只显示与工作区的游戏和 LeviLamina 相配的版本。需要其他 LeviLamina 版本的旧版本或新版本不会出现，哪怕 levimc.org 上列着它。

所选变体没有任何相配的版本时，会有一行说明无法匹配的原因：

![LeviLamina 为 26.40.1 的服务器里，LeviOptimize 的版本对话框。有一行写着“没有适用于 LeviLamina 26.40.1 的版本。”，只剩“自定义…”一行。](/screenshots/zh-Hans/get-mods-21-none-fits.svg)

1. 没有版本与之相配的 LeviLamina（或游戏）。
2. **自定义…** 仍然可用。

这时有三种办法：换一个变体，换一个模组，或者在[服务器](./server.md)页面用**更改版本…**更改服务器的游戏和 LeviLamina 版本。

### 自定义…

最后一行**自定义…** 让你自己指定要安装的内容。想装某个分支、标签或提交时（比如试用尚未发布的修复），可以用它。

![“自定义版本”对话框。标签是模组名加“@”，灰色的“branch:main”是示例。](/screenshots/zh-Hans/get-mods-22-custom.svg)

输入 `@` 后面的部分：版本号（比如 `1.8.0`），或者 `branch:main`、`tag:` 加标签名、`rev:` 加提交。按 `Enter` 查看计划，按 `Esc` 回到版本列表。

lip 不会事先检查你指定的内容是否与服务器相配。如果不相配，计划会失败并说明原因，不会改动任何内容。

## 在没有服务器的文件夹里

在哪里都可以浏览模组，但安装需要服务器，因为模组版本必须与游戏相配。在没有服务器的文件夹里，点**安装…** 会先请你安装服务器：

![对话框写着“此文件夹还没有服务器，请先安装。”，按钮是“安装服务器…”和“取消”。](/screenshots/zh-Hans/get-mods-20-no-server.svg)

**安装服务器…** 会转到[服务器](./server.md)页面，在那里开始安装服务器。

## 服务器运行期间

工作区的服务器运行期间不能安装任何东西。此时**安装…** 是灰色的，菜单会说明原因。“README”和“在浏览器中打开”照常可用。

![服务器运行期间一个模组的菜单。“安装…”是灰色，有一行写着“请先停止服务器。”](/screenshots/zh-Hans/get-mods-19-server-running.svg)

请先到[服务器](./server.md)页面停止服务器。

## 读不到列表时

lip 无法从 levimc.org 读取列表时，页面不会显示模组，而是说明情况。

![市场页面写着“无法读取模组目录。”，接着是原因，还有一个“重试”按钮。](/screenshots/zh-Hans/get-mods-24-unreachable.svg)

1. 无法读取列表。
2. 原因（lip 的原话）。
3. **重试**重新读取列表。

请检查网络连接，然后按 `Enter`。[设置](./settings.md)页面的 GitHub 代理不会用于 levimc.org，因此在这里不起作用。

如果知道模组名字，仍然可以用[模组](./mods.md#从来源安装)页面的**从来源安装…**来安装。
