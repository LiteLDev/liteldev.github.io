# 主页

主页是 lip 启动后显示的第一个页面。读完本文，你就能看懂它对文件夹的概览，按它的步骤启动服务器，并知道 lip 连不上 GitHub 时该如何应答。

如果你还不熟悉按键和屏幕上的各个部分，请先阅读[界面导览](./tour.md)。

## 概览

页面上半部分展示了工作区（lip 当前操作的文件夹）里的内容。

![一个有服务器、还没有模组的文件夹的主页。编号标出概览、已完成的步骤、高亮的步骤和步骤下方的一句话。](/screenshots/zh-Hans/home-03-server-created.svg)

1. 概览。各行的含义见下表。
2. 带 `✓` 的步骤已经完成。
3. 高亮的步骤是接下来该做的一步。
4. 一句话说明在高亮步骤上按 `Enter` 会执行的操作。

| 行 | 显示 |
| --- | --- |
| 工作区 | 文件夹路径。路径太长时会截掉开头，保留末尾。 |
| 游戏 | 文件夹里 Minecraft 服务器的版本，或者“未安装”。 |
| 加载器 | LeviLamina 及其版本，或者“无”。模组需要加载器。 |
| 模组 | 你安装的模组数量。作为其他模组的依赖而安装的模组不算在内，游戏和加载器也不算。 |
| 服务器 | “未运行”，或者 `●` 加“运行中”。按下启动后、服务器程序跑起来之前显示“正在启动”。刚让服务器停止时显示“正在停止”；lip 等待重启崩溃的服务器时显示“正在重启”。 |

页面刚打开的一瞬间，各行会显示 `…`，表示 lip 正在读取文件夹。

## 下一步

概览下方的**下一步**列出了从选定文件夹到运行服务器的四个步骤。lip 会自动高亮第一个未完成的步骤，因此大多数时候你只需按 `Enter`。

用 `↑` 和 `↓` 在步骤间移动，按 `Enter` 打开高亮的步骤。

| 步骤 | 何时算完成 | 按 `Enter` |
| --- | --- | --- |
| 1 选择工作区 | 始终完成：总有一个当前工作区。 | 打开[工作区选择器](./workspaces.md)，选择或添加其他文件夹。 |
| 2 安装服务器 | 文件夹里有了游戏。 | 打开[服务器](./server.md)页面并开始[安装服务器](./server.md#安装服务器)。 |
| 3 安装模组 | 你至少安装了一个模组。 | 打开[市场](./get_mods.md)页面。 |
| 4 启动服务器 | 服务器正在运行。 | 打开[服务器](./server.md)页面并启动服务器。 |

### 还没有安装服务器

在没有服务器的文件夹里，只有第 1 步打勾，高亮的是第 2 步。

![空文件夹的主页。只有“选择工作区”打勾，“安装服务器”处于高亮。下方的一句话是“为此工作区选择游戏版本和加载器。”](/screenshots/zh-Hans/home-01-empty.svg)

1. 当前显示的页面。左侧边栏列出了所有页面。
2. 下一步：按 `Enter` 开始。
3. 当前可用的按键。

按 `Enter` 在该文件夹中安装服务器。后续步骤见[开你的第一个服务器](https://levimc.org/zh-Hans/tutorials/server/first-server/)。如果要把服务器装到其他文件夹，请先通过第 1 步选中那个文件夹。

### 服务器已安装

文件夹里有了游戏后，第 1、2 步打勾，高亮移至第 3 步。本页开头的截图就是这个状态。按 `Enter` 即可浏览 levimc.org 上的模组。

第 3 步可以跳过。不装模组服务器也能运行：按 `↓` 再按 `Enter` 即可直接启动。

### 模组已安装

至少安装一个模组后，第 1 到 3 步打勾，高亮移至第 4 步。

![装了四个模组的服务器的主页。第 1 到 3 步已打勾，“启动服务器”处于高亮。](/screenshots/zh-Hans/home-04-mods-installed.svg)

按 `Enter`，lip 会打开服务器页面并启动服务器。

### 服务器正在运行

服务器运行期间，四个步骤全部打勾。顶部栏和概览都会显示“运行中”。

![服务器运行期间的主页。四个步骤全部打勾，顶部一行显示“运行中”。](/screenshots/zh-Hans/home-02-all-done.svg)

此时在第 4 步上按 `Enter` 只会打开服务器页面，不会重复启动；步骤下方的说明会变为**运行中。按 Enter 打开控制台。**

### 已完成的步骤还能再打开

打勾不代表锁定。在第 1 步上按 `Enter` 随时可以打开工作区选择器；在第 3 步上按 `Enter` 随时可以打开“市场”，继续安装其他模组。在已打勾的第 2 步上按 `Enter` 则会重新开始安装流程，用于更改服务器的游戏版本或加载器版本。

![第 2 步已打勾并处于高亮。下方的一句话是“已完成。按 Enter 更改游戏或加载器版本。”](/screenshots/zh-Hans/home-05-step-done.svg)

### 没有服务器时启动

没有服务器的文件夹里无从启动。此时若在第 4 步上按 `Enter`，lip 会在底栏右侧显示“请先安装服务器。”，并把高亮移回第 2 步。

![空文件夹的主页，在第 4 步上按 Enter 之后。底部一行显示“请先安装服务器。”，第 2 步重新高亮。](/screenshots/zh-Hans/home-06-need-server.svg)

1. 提示消息，几秒后自动消失。
2. 高亮回到了安装服务器这一步。

## 连不上 GitHub 时

LeviLamina 和大多数模组都从 GitHub 下载。每次启动界面，lip 都会在后台检查能否连上 GitHub。它最多等待 10 秒，在此期间你可以照常使用界面。

如果检查失败，lip 会询问该如何连接 GitHub。它会等到没有其他对话框打开时才弹窗，不会打断你手头的操作。

![“无法连接 GitHub”对话框。它说明连接失败的原因，询问“lip 应如何连接 GitHub？”，并给出“使用代理”“直接连接”和“以后再说”三个回答。](/screenshots/zh-Hans/home-07-github.svg)

1. lip 连不上 GitHub 的原因。
2. 三个选项，默认高亮第一项。
3. 当前高亮选项的简短说明。

用 `↑` 和 `↓` 选择，按 `Enter` 确认。在你确认之前，不会更改任何设置。

::: info
只要你在[设置](./settings.md)页面配置过 GitHub 代理，或者选择过直接连接，lip 就不会再做这项检查。
:::

### 使用代理

如果你所在的网络访问 GitHub 很慢或受到屏蔽，且你知道可用的 GitHub 代理网址，请选这一项。lip 不会推荐任何代理。

lip 会打开[设置](./settings.md)页面并让你输入代理网址。

![设置页面上的“GitHub 代理”对话框，“代理网址”文本框里是用户输入的网址。](/screenshots/zh-Hans/home-11-github-proxy.svg)

输入网址后按 `Enter`。lip 会先测试该代理，可用即保存；若不可用，你可以换一个网址，也可以强制保存当前网址。完整说明见设置页面。

在该对话框中按 `Esc` 不会保存任何内容，lip 下次启动时会再次询问。

### 直接连接

如果你平时能正常访问 GitHub，这次检查失败只是偶然情况（例如网络刚好闪断），请选这一项。

![“直接连接”处于高亮。下方的一句话是“保持直接连接，不再询问。”](/screenshots/zh-Hans/home-08-github-direct.svg)

lip 会记住使用直接连接，并在底栏给出提示。此后它不再检查，也不再询问。

![主页。底部一行的右侧是消息“已设为直接连接。”](/screenshots/zh-Hans/home-10-github-direct-saved.svg)

日后如果想改，到[设置](./settings.md)页面设置或清除 GitHub 代理即可。

### 以后再说

如果暂时不想决定，请选这一项。按 `Esc` 效果相同。

![“以后再说”处于高亮。下方的一句话是“不做更改，下次启动时再问。”](/screenshots/zh-Hans/home-09-github-later.svg)

lip 不会做任何更改。下次启动界面时它会再次检查，若依然失败则再次询问。

::: warning
在连上 GitHub 之前，安装带 LeviLamina 的服务器和安装大多数模组都会失败，并弹出错误对话框说明 lip 无法连接服务器。参见[故障排除](../guides/troubleshooting.md)。
:::
