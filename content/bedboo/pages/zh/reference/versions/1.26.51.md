# 基岩版 1.26.51

1.26.51 协议族（默认版本）涵盖 **协议 2193**，对应 BDS **1.26.50.5**、**1.26.51.1** 与 **1.26.52.3**。向 `createBot` 传入 `version: '1.26.51'` 或上述任一 BDS 版本即可选用该协议族（不传或传入 `false` 时同样默认为 1.26.51）；此时 `bot.version` 为 `'1.26.51'`，`bot.protocolVersion` 为 2193。除非页面另有说明，本参考文档的其余内容均基于此协议族（详见 [BDS 笔记](../bds.md) 与 [连接与版本](../differences/connection.md#versions)）。

## 数据 {#data}

`@bedboo/bedrock-data` 提供了 `data/1.26.51/`，由 `scripts/generate.js --version 1.26.51` 根据 `scripts/sources.js` 中 `PINS['1.26.51']` 固定的数据源以及实机探测结果 `scripts/probe/1.26.51.json`（BDS 1.26.51.1）生成，包含 22 091 个方块状态、2 076 个物品与 89 个原版生物群系。数据来源列于该包的 `NOTICE.md` 中。

## 三个 BDS 版本共用一套数据 {#builds}

这三个 BDS 版本的协议与游戏数据完全一致。我们原生启动了各个版本，以 `version: '1.26.51'` 加入服务器，并将加入时收到的静态数据与用于生成数据的 BDS 1.26.51.1 进行了比对：

| 对比项 | 1.26.50.5 | 1.26.52.3 |
|---|---|---|
| `start_game`：方块调色板校验和、`block_network_ids_are_hashes`、98 个 `block_properties`、实验性玩法、游戏规则 | 相同 | 相同 |
| `item_registry`：2 076 个物品，运行时 id、`component_based` 与版本均相同 | 相同 | 相同 |
| `creative_content`：124 个分组、1 980 个条目 | 相同 | 相同 |
| `biome_definition_list`：89 个定义 | 相同 | 相同 |
| `crafting_data`：所有配方及其网络 id（每次运行随机生成的配方 UUID 除外） | 相同 | 相同 |
| `available_entity_identifiers`、`voxel_shapes`、`trim_data`、`camera_presets`、`unlocked_recipes` 等 | 相同 | 相同 |
| `available_commands`：82 个命令及其重载、参数类型 id 与枚举内容 | 相同 | 相同 |
| 探测：状态效果 id、附魔 id、生物群系顺序、实体碰撞箱 | 相同 | 相同 |

仅有的几处差异均局限于服务端内部，或不影响客户端行为：

- `start_game.engine` 为各自的版本号（`1.26.50`、`1.26.52`）。
- `available_commands` 中 `/place feature` 的世界生成特征名称顺序不同（名称集合相同）；bedboo 根据每个数据包自带的值表解析枚举值，不依赖顺序。
- BDS 1.26.50.5 发送的 `jigsaw_structure_data` 模板池不同（用于结构生成，bedboo 不使用）。

因此，`data/1.26.51/`、特性表与命令类型 id 同时适用于这三个版本，无需为单个 BDS 版本维护独立的表。bedboo 也已在各个版本上完成了实机测试（涵盖出生、注册表、`blockAt`、物品栏、聊天、物理行走、挖掘、放置、实体跟踪、Tab 补全与断开连接），表现完全一致。

## 测试 {#tests}

`pnpm test` 会针对此协议族运行单元测试（可通过 `BEDBOO_VERSION=1.26.51` 或 `BEDBOO_VERSION=1.26.52.3` 等 BDS 版本显式指定）。对应的进服抓包数据位于 `test/fixtures/1.26.51/join_flat`（采自 BDS 1.26.51.1）。
