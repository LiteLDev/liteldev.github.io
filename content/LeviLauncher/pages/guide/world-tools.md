# World Tools

LeviLauncher includes utilities to help you protect and inspect your worlds.

## Main world tools

- Export a world as a backup package, such as `.mcworld`
- Inspect world information
- Edit selected `level.dat` fields
- Safely rename a world through the launcher

## When to back up a world

Always create a backup before you:

- Test Minecraft Preview versions
- Install or update multiple mods
- Change important world metadata
- Move a world between very different setups

## Editing `level.dat`

LeviLauncher exposes selected fields from `level.dat` for easier editing.

::: warning Edit carefully
`level.dat` contains sensitive world metadata. Back up your world first, and change only the settings you understand.
:::

## Recommended backup routine

1. Back up before major updates.
2. Back up before adding new mods or packs.
3. Keep at least one backup outside the version workspace.
