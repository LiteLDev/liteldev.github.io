# Как загружаются моды

В Minecraft Bedrock нет встроенной поддержки модов: мод — это нативный код, который загрузчик внедряет в процесс игры при запуске. Здесь описано, какие загрузчики использует LeviLauncher, где хранятся моды и как устроены разные способы их добавления.

## Где лежат моды <Badge platform="windows" />

У каждого инстанса есть папка `mods\` (см. [Папки и файлы](../reference/files)). Каждый мод лежит в ней отдельной папкой и содержит файл `manifest.json` с описанием:

| Поле | Значение |
| --- | --- |
| `name` | Имя мода. |
| `entry` | Загружаемый файл (`.dll`), путь задаётся относительно папки мода. |
| `version` | Версия мода. |
| `type` | Нужный загрузчик: `preload-native` — нативный загрузчик LeviLauncher; у модов для LeviLamina свои типы. |
| `author` | Автор (необязательно). |

Моды привязаны к конкретному инстансу. [Изоляция](./isolation) на них не влияет — она касается только игровых данных.

**Выключение мода** (в **Управлении модами** или командой `LeviLauncher.exe mod disable`) переименовывает его `manifest.json` в `manifest.json.close`, а включение возвращает прежнее имя. Сами файлы мода остаются на месте, но загрузчик ищет именно `manifest.json` и поэтому пропускает отключённый мод.

## Два загрузчика <Badge platform="windows" />

### Нативный загрузчик LeviLauncher

Устанавливая или подготавливая инстанс, LeviLauncher кладёт свой загрузчик `LeviLauncher.dll` рядом с исполняемым файлом игры и прописывает его в таблицу импорта этого файла, чтобы Windows загружала библиотеку вместе с игрой. Это работает для сборок x64 (как GDK, так и UWP); на этом же механизме держится [изоляция](./isolation).

При запуске игры нативный загрузчик обходит папки в `mods\` по алфавиту и загружает `entry` каждого мода с `type`, равным `preload-native`. Папки без `manifest.json` и моды других типов он пропускает. Если у инстанса есть другой предзагрузчик (`preloader.dll` рядом с игрой), нативный загрузчик полностью передаёт загрузку модов ему. Для работы нативного загрузчика нужна среда выполнения Visual C++ (x64) — LeviLauncher проверяет её наличие и при необходимости предлагает установить.

### LeviLamina

[LeviLamina](https://levimc.org/LeviLamina/) — загрузчик модов от LeviMC. Большинство модов в каталоге [LeviMC Mods](https://levimc.org/mods/) написаны под LeviLamina: им нужна версия загрузчика, совместимая с версией игры в инстансе. LeviLauncher устанавливает LeviLamina в инстансы GDK поддерживаемых версий через встроенный менеджер пакетов — включить её можно переключателем **Установить LeviLamina** при установке версии или на вкладке **Загрузчик** в **Настройках инстанса**.

## Три способа добавить мод <Badge platform="windows" />

| Что вы добавляете | Что делает LeviLauncher |
| --- | --- |
| Мод из **LeviMC Mods** (или `mod install owner/repo`) | Устанавливает его как пакет через встроенный менеджер пакетов, совместимый с [lip](https://github.com/LiteLDev/lip): скачивает релиз для текущей платформы, ставит зависимости и записывает пакет в `.lip\state.json` инстанса. Если моду нужна LeviLamina, а она не установлена или её версия не подходит, сначала ставится совместимая версия LeviLamina. Такие моды можно обновлять и удалять как обычные пакеты. |
| Пакет `.mcmod` (или `.zip`) | Распаковывает архив в новую папку внутри `mods\`. В архиве должен быть `manifest.json`. |
| Отдельный `.dll` | Кладёт файл в новую папку внутри `mods\` и создаёт для него `manifest.json`: по умолчанию в качестве имени берётся имя файла, в качестве типа — `preload-native`, а в качестве версии — `0.0.0`. |

Целевое окружение пакета задаётся полями `side` (`client` или `server`) и `platform` (например, `win-x64`) в его `lip.toml` и в `.lip\state.json`. Для клиента LeviLauncher устанавливает вариант мода `client`, а если его нет — вариант по умолчанию. Подробнее об этом, в том числе о миграции старых пакетов, рассказано в разделе [Моды и интеграции](../guide/mods-integrations).

## Android <Badge platform="android" />

Версия для Android загружает нативные моды — библиотеки `.so`, которые работают в процессе игры. Держите сборки с модами в изолированных версиях и устанавливайте моды только из надёжных источников. Чтобы написать собственный мод, следуйте руководству [Android native mods](https://levimc.org/LeviLamina/developer_guides/android/) в документации LeviLamina.
