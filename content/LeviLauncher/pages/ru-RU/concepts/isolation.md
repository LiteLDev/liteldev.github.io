# Изоляция инстансов

Minecraft хранит миры, паки и настройки в одной папке игровых данных на устройство. **Изоляция инстанса** (в приложении: **Включить изоляцию** в **Настройках инстанса** и **Изоляция инстанса** при установке версии) выделяет инстансу собственную папку игровых данных внутри папки самого инстанса. В командной строке эти два режима называются *own data* (собственные данные) и *shared data* (общие данные).

## Общие и собственные данные

=== "Windows"

    Инстанс **без изоляции** использует стандартную папку игровых данных Minecraft на этом ПК: те же миры, паки и настройки, что и игра из Microsoft Store и любой другой неизолированный инстанс того же типа.

    Инстанс **с изоляцией** хранит игровые данные в своей папке. Его миры, ресурс-паки, поведенческие паки, паки скинов, скриншоты, список серверов и настройки игры отделены от всех остальных инстансов и от игры из Microsoft Store.

    | Инстанс | Общие данные (изоляция выключена) | Собственные данные (изоляция включена) |
    | --- | --- | --- |
    | GDK, Release | `%APPDATA%\Minecraft Bedrock` | `<инстанс>\Minecraft Bedrock` |
    | GDK, Preview | `%APPDATA%\Minecraft Bedrock Preview` | `<инстанс>\Minecraft Bedrock Preview` |
    | UWP, Release | `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState` | `<инстанс>\Minecraft Bedrock` |
    | UWP, Preview | `%LOCALAPPDATA%\Packages\Microsoft.MinecraftWindowsBeta_8wekyb3d8bbwe\LocalState` | `<инстанс>\Minecraft Bedrock Preview` |
    | UWP, Beta | `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState` | `<инстанс>\Minecraft Bedrock Beta` |

    `<инстанс>` — папка инстанса в `Instances` (см. [Папки и файлы](../reference/files)). В папке данных GDK игра хранит данные каждого игрока в `Users\` (см. [профили игроков](./instances#player-profiles)), а в папке данных UWP — в `games\com.mojang\`.

=== "Android"

    При изоляции версий игровые данные версии (миры, паки и настройки) хранятся отдельно от других версий и от Minecraft, установленного из Google Play. Изменение этого параметра для одного инстанса не затрагивает остальные. Импортированным версиям для запуска часто требуется изоляция.

## Как это работает <Badge platform="windows" />

Сама игра ничего не знает об инстансах. При установке инстанса LeviLauncher помещает свой загрузчик `LeviLauncher.dll` рядом с исполняемым файлом игры (см. [Как загружаются моды](./mod-loading)). При запуске игры с включённой изоляцией загрузчик перенаправляет папки, где игра ищет свои данные (папки данных приложения и временную папку), в папку данных инстанса. Файлы не копируются и не связываются симлинками — игра просто сразу читает и пишет по новому пути.

На что изоляция не влияет:

- **Моды** всегда привязаны к инстансу и лежат в его папке `mods\`, независимо от изоляции.
- **Аккаунт Microsoft** и настройки самого лаунчера едины для всех инстансов.
- **Регистрация** в Windows (см. [Инстансы и версии игры](./instances#registration-with-windows)) не зависит от изоляции.

## Ограничения <Badge platform="windows" />

- Инстансы GDK поддерживают изоляцию на всех версиях; инстансы UWP — начиная с версии 1.19.70.2 и только для архитектуры x64.
- При включении изоляции данные не копируются: инстанс запускается с чистыми игровыми данными. Чтобы перенести существующие данные, выберите их копирование при установке версии (из установленной на ПК игры или из другого изолированного инстанса того же типа) либо скопируйте их позже командой `LeviLauncher.exe instance copy-data` (для GDK).
- Если выключить изоляцию, инстанс вернётся к общим данным, а его собственная папка данных останется внутри папки инстанса.
- При удалении инстанса удаляется вся его папка, **включая миры его собственных данных**. Заранее создайте резервную копию важных миров (см. [Инструменты для миров](../guide/world-tools)).
- Копировать контент из одного инстанса в другой можно только тогда, когда целевой инстанс использует собственные данные или это инстанс UWP с другой папкой данных.

## Когда использовать

Изоляция полезна, когда нужны:

- разные наборы контента для разных версий;
- безопасная среда для тестирования модов или сборок Minecraft Preview;
- защита одних сборок от влияния других.

Удобная схема: один изолированный инстанс Release для обычной игры, один изолированный инстанс Preview по мере необходимости и один временный инстанс для проверки модов или диагностики.
