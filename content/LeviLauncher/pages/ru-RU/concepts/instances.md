# Инстансы и версии игры

LeviLauncher устанавливает каждую копию Minecraft как **инстанс** — отдельную версию игры со своим именем, своими настройками и, если нужно, своими игровыми данными. Можно держать несколько инстансов одновременно — одной или разных версий — и запускать нужный. Все они показаны на странице **Инстансы**.

## Что такое инстанс

=== "Windows"

    Инстанс — это папка внутри папки `Instances` лаунчера (см. [Папки и файлы](../reference/files)). Имя инстанса совпадает с именем папки. В ней лежат:

    - файлы игры одной сборки Minecraft, распакованные из её установщика;
    - `.levilauncher\instance.json` — сведения об инстансе: версия игры, канал, хранит ли он собственные игровые данные, и параметры запуска (консоль, режим редактора, аргументы запуска, переменные окружения);
    - `mods\` — моды инстанса, а также `.lip\` — состояние пакетов, установленных встроенным пакетным менеджером (см. [Как загружаются моды](./mod-loading));
    - собственные игровые данные инстанса (миры, паки, настройки), если для него включена [изоляция](./isolation).

    Моды всегда принадлежат конкретному инстансу. Игровые данные принадлежат инстансу, только когда включена изоляция; иначе он использует общие данные Minecraft на этом ПК.

=== "Android"

    Инстанс — это официальный APK Minecraft, импортированный в LeviLauncher. Он работает внутри лаунчера без установки в систему. При этом на устройстве всё равно должен быть установлен Minecraft из Google Play (1.21.80 или новее); LeviLauncher показывает его рядом с импортированными версиями.

    Изоляция версий хранит миры, паки и настройки импортированной версии отдельно от установленной игры из Google Play. Импортированным версиям для запуска часто требуется изоляция.

## Release и Preview

Каждая сборка Minecraft относится к **каналу**:

| Канал | Что это |
| --- | --- |
| Release | Стабильная версия игры, которой пользуется большинство игроков. |
| Preview | Тестовые сборки будущих версий. Чаще ломают миры, паки или моды. |
| Beta | Тестовые сборки, которые выходили только для UWP. <Badge platform="windows" /> |

В Windows у Release и Preview разные папки игровых данных (`Minecraft Bedrock` и `Minecraft Bedrock Preview`), поэтому у инстансов Preview и Release даже без изоляции миры не общие.

## Сборки GDK и UWP <Badge platform="windows" />

Minecraft для Windows выходил в двух форматах пакетов, и LeviLauncher поддерживает оба. Если версия доступна в обоих форматах, лаунчер выбирает GDK.

| | GDK | UWP |
| --- | --- | --- |
| Установщик | `.msixvc`, скачивается с зеркала, которое LeviLauncher тестирует на скорость и выбирает автоматически | `.appx` / `.msix` (или пакет-бандл), скачивается из Центра обновления Windows |
| Для установки | Вход в аккаунт Microsoft, на котором куплен Minecraft | — |
| Для запуска | Microsoft Gaming Services и Microsoft GameInput | Режим разработчика Windows для регистрации пакета в системе |
| Общие игровые данные | `%APPDATA%\Minecraft Bedrock` (Preview: `Minecraft Bedrock Preview`), отдельная папка на каждый профиль игрока в `Users\` | `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState` (Preview: `Microsoft.MinecraftWindowsBeta_8wekyb3d8bbwe`) |
| Изоляция | Все версии | Версии x64 1.19.70.2 и новее |
| LeviLamina | Устанавливается через LeviLauncher на поддерживаемых версиях | LeviLauncher не устанавливает |
| Аргументы запуска и переменные окружения | Да | Нет |

При импорте локального установщика (`.msixvc`, `.appx`, `.msix`, `.appxbundle` или `.msixbundle`) тип инстанса — GDK или UWP — определяется по расширению файла.

### Профили игроков {#player-profiles}

Инстанс GDK хранит миры, скриншоты и список серверов отдельно для каждого **профиля игрока**: это папка в `Users\`, названная по ID игрока (в лаунчере рядом отображается его gamertag, если он известен). Ресурс-паки и поведенческие паки общие для всех профилей (`Users\Shared\`); паки скинов стали общими с версии 1.26, а до этого тоже хранились по профилям. У инстансов UWP профилей нет.

## Регистрация в Windows <Badge platform="windows" /> {#registration-with-windows}

Для каждого канала Windows распознаёт только одну установленную копию Minecraft. **Регистрация** инстанса указывает системе считать основной игрой именно его: через этот инстанс начинают работать ярлык в меню «Пуск», ссылки `minecraft://` и функции Xbox. При регистрации инстанс заменяет текущую игру на канале Release или Preview (будь то версия из Microsoft Store или другой инстанс), но её данные сохраняются. Ни регистрация, ни её отмена никогда не затрагивают игровые данные.

Инстансы UWP регистрируются при запуске автоматически. Чтобы переименовать или удалить зарегистрированный инстанс, сначала нужно отменить его регистрацию.
