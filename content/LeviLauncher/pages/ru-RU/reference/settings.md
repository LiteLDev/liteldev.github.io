# Все настройки

Здесь перечислены все настройки со страницы **Настройки** версии для Windows по вкладкам (для LeviLauncher 1.1.0), а также ключ `config`, которым настройку можно изменить из [командной строки](./command-line), если он предусмотрен. Найти настройку по названию можно через поле поиска вверху страницы. Рекомендации по выбору параметров приведены в разделе [Настройки и персонализация](../guide/settings-personalization).

## Основные настройки

| Настройка | Что делает | Ключ |
| --- | --- | --- |
| **Пути к контенту → Базовая папка** | Корневая папка данных, в которой хранятся инстансы, загрузки и резервные копии (см. [Папки и файлы](./files)). **Применить** сохраняет выбранную папку, **Сбросить** возвращает папку по умолчанию. Ниже отображаются пути к папкам **Установщики** и **Версии**. Существующие данные не перемещаются. | `data-root` |
| **Язык** | Язык интерфейса лаунчера. | — |
| **Discord Rich Presence** | Отображает статус игры в Discord. По умолчанию включено. | `discord` |
| **При запуске Minecraft** | Действие лаунчера при запуске Minecraft: **Сворачивать лаунчер** (по умолчанию), **Скрывать в системный трей**, **Закрывать лаунчер** или **Оставлять открытым**. | `on-game-launch` |
| **После закрытия Minecraft** | Действие лаунчера после закрытия Minecraft: **Разворачивать лаунчер** (по умолчанию), **Ничего не делать** или **Закрывать лаунчер**. | `on-game-exit` |
| **Скрывать в трей при закрытии** | Кнопка закрытия сворачивает лаунчер в системный трей вместо выхода из программы; кнопка сворачивания по-прежнему убирает окно на панель задач. По умолчанию выключено. | `close-to-tray` |

## Персонализация

Вкладка разделена на четыре части. Параметры персонализации (цвета, непрозрачность и т. д.) сохраняются отдельно для светлой и тёмной темы (**Настройки для каждого режима**): чтобы настроить одну из них, выберите **Светлая тема** или **Темная тема**.

### Тема и цвета

| Настройка | Что делает |
| --- | --- |
| **Режим темы** | **Светлая тема**, **Темная тема**, **Расписание** (тёмная тема действует между **Временем начала ночного режима** и **Временем окончания ночного режима**), **Восход/Закат** (по местному времени восхода и заката, рассчитанному на устройстве) или **Как в системе** (используется настройка Windows). |
| **Цвет темы** | Акцентный цвет: один из вариантов в наборах **Стандартных цветов** и **Больше цветов** либо **Пользовательский цвет**. |
| **Режим основы** | Сплошная цветовая подложка под фоновым изображением для повышения контраста: **Нет**, **Цвет темы** или **Пользовательский цвет основы**, а также настройка **Непрозрачностью основы**. |

### Компоновка и анимация

| Настройка | Что делает |
| --- | --- |
| **Использовать верхнюю панель навигации** | Размещает панель навигации сверху вместо боковой панели. |
| **Отключить анимацию** | Отключает анимацию переходов в интерфейсе. |

### Обои

| Настройка | Что делает |
| --- | --- |
| **Фоновое изображение** | Папка с фоновыми изображениями: доступны действия **Выбрать изображение**, **Открыть папку**, **Очистить изображение** и **Следующее изображение** (если в папке несколько картинок). |
| **Режим заполнения** | **Умное заполнение**, **По центру**, **Вписать**, **Растянуть**, **Замостить**, **Сверху слева** или **Сверху справа**. |
| **Порядок воспроизведения** | **Случайно** или **Последовательно** (в естественном порядке имён файлов). |
| **Размытие фона**, **Яркость фона**, **Непрозрачность фона** | Параметры отображения фоновой картинки. |

### Материалы и читаемость

| Настройка | Что делает |
| --- | --- |
| **Материал интерфейса** | Оформление панели навигации, карточек, вкладок, элементов управления и всплывающих окон поверх обоев. **Предустановки материала**: **Сбалансированный** (по умолчанию), **Прозрачный** или **Сплошной**. |
| **Непрозрачность интерфейса**, **Размытие интерфейса**, **Затемнение обоев** | Тонкая настройка материала. |
| **Защита читаемости** | Поддерживает читаемость текста, слегка тонируя поверхности с учётом выбранной темы, яркости и размытия фона. |
| **Сбросить эту тему** | Сбрасывает настройки материала для редактируемой темы. |

Подробно эти параметры описаны в разделе [Настройки и персонализация](../guide/settings-personalization#обои-и-материал-интерфеиса).

## Управление пакетами

| Настройка | Что делает | Ключ |
| --- | --- | --- |
| **Очистить кэш** | Удаляет файлы пакетов, скачанные менеджером пакетов. Используйте при сбоях загрузки пакетов. | `cache clean packages` |
| **Использовать зеркала** | Загружает обновления лаунчера, пакеты и списки версий с зеркал в материковом Китае. По умолчанию включено для пользователей из материкового Китая. | `mirror` |
| **Прокси GitHub** | Прокси-сервер GitHub для загрузки пакетов (отображается, когда включена опция **Использовать зеркала**): можно выбрать предустановку или **Свой**, чтобы указать собственный URL. Пустое поле возвращает адрес по умолчанию (`https://gh-proxy.org/https://github.com`). | `github-proxy` |

## Ключи командной строки {#command-line-keys}

Команда `LeviLauncher.exe config list` выводит все ключи, их значения и источник каждого значения: `set` (сохранено), `default` (по умолчанию), `auto` (определено автоматически) или `lip` (из собственного `config.toml` lip). Команда `config set <key> <value>` меняет значение ключа, а `config unset <key>` сбрасывает его к значению по умолчанию.

| Ключ | Значения | Описание |
| --- | --- | --- |
| `data-root` | папка | Папка для инстансов, загрузок и резервных копий (существующие данные не перемещаются) |
| `default-instance` | инстанс | Инстанс, который используют команды, если не указан другой (аналог `use`) |
| `mirror` | `on`, `off` | Скачивать файлы с зеркал в материковом Китае (если не задано, определяется по региону) |
| `github-proxy` | URL http(s) | Прокси GitHub для загрузки модов (если не задан, используется при включённых зеркалах) |
| `beta-updates` | `on`, `off` | Предлагать предварительные обновления лаунчера (по умолчанию `off`) |
| `discord` | `on`, `off` | Показывать статус Discord Rich Presence во время игры, только при запуске из окна лаунчера (по умолчанию `on`) |
| `on-game-launch` | `minimize`, `hide`, `close`, `keep` | Действие окна лаунчера при запуске игры (по умолчанию `minimize`) |
| `on-game-exit` | `reopen`, `keep`, `close` | Действие окна лаунчера после выхода из игры (по умолчанию `reopen`) |
| `close-to-tray` | `on`, `off` | Сворачивать лаунчер в трей при закрытии окна (по умолчанию `off`) |

Ключи только для чтения, которые выводят команды `config list` и `config get`: `instances-dir`, `installers-dir`, `backups-dir`, `cache-dir`, `logs-dir` (папки, описанные в разделе [Папки и файлы](./files)) и `config-file` (файл настроек `%APPDATA%\LeviLauncher\config.json`).
