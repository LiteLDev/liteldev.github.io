# Командная строка

Запущенный без аргументов, `LeviLauncher.exe` открывает окно лаунчера. С командой он отрабатывает в терминале и завершается; команды строятся по схеме `<существительное> <глагол>`:

```text
LeviLauncher.exe <command> [arguments] [flags]
```

На этой странице перечислены все команды LeviLauncher 1.1.0. Команда `LeviLauncher.exe help` выводит общий обзор, а `LeviLauncher.exe help <command>` — флаги и примеры для конкретной команды. Вывод командной строки — на английском языке.

```text
LeviLauncher.exe install latest --loader --use
LeviLauncher.exe play
LeviLauncher.exe mod install LiteLDev/LegacyMoney
LeviLauncher.exe world export "My World" -o D:\Backups
LeviLauncher.exe instance list --json
```

## Запуск из оболочки

`LeviLauncher.exe` — оконная программа, поэтому командные оболочки по умолчанию не ждут её завершения. Если нужно дождаться вывода перед возвратом приглашения или получить код возврата:

- в cmd используйте `start /wait LeviLauncher.exe ...`, затем прочитайте `%ERRORLEVEL%`;
- в PowerShell передайте вывод по конвейеру (`LeviLauncher.exe instance list | Out-String`) или используйте `Start-Process -Wait -NoNewWindow`.

В режиме командной строки лаунчер не открывает окно и может работать параллельно с уже открытым окном.

## Команды

### На каждый день

| Команда | Что делает |
| --- | --- |
| `play [<instance>]` | Запускает игру и ждёт появления её окна (псевдоним `launch`) |
| `install <version\|file>` | Скачивает и устанавливает Minecraft как новый инстанс (= `instance create`) |
| `use [<instance>]` | Задаёт или показывает инстанс по умолчанию |
| `stop [<instance>\|<pid>...]` | Закрывает запущенный Minecraft (= `process stop`) |

### Управление инстансом

| Команда | Что делает |
| --- | --- |
| `instance list [<filter>]` | Список установленных инстансов |
| `instance show [<instance>]` | Показывает настройки, регистрацию, загрузчик, игроков и количество контента инстанса (также `instance <instance>`) |
| `instance create <version\|file>` | Скачивает и устанавливает Minecraft как новый инстанс |
| `instance copy-data [<instance>] --from system\|<instance>` | Копирует игровые данные (миры, настройки) в инстанс с собственными данными |
| `instance rename <instance> <new-name>` | Переименовывает инстанс |
| `instance set [<instance>]` | Меняет настройки инстанса (консоль, режим редактора, собственные данные, аргументы, окружение, логотип) |
| `instance remove <instance>...` | Безвозвратно удаляет инстансы и всё содержимое их папок |
| `instance register [<instance>]` | Регистрирует этот инстанс в Windows как установленный Minecraft соответствующего канала |
| `instance unregister [<instance>]` | Снимает регистрацию инстанса в Windows (игровые данные сохраняются) |
| `instance shortcut [<instance>]` | Создаёт или удаляет ярлык на рабочем столе для запуска инстанса |
| `instance path [<instance>] [<kind>]` | Выводит путь к папке инстанса (и при необходимости открывает её) |
| `mod list [<filter>]` | Список модов инстанса |
| `mod show <package>` | Показывает мод из каталога |
| `mod search [<words>]` | Ищет моды в каталоге LeviLamina |
| `mod install <package[@version]>...` | Устанавливает, обновляет или откатывает версию модов из каталога |
| `mod update [<mod>...]` | Обновляет моды из каталога до последней версии |
| `mod import <file>...` | Добавляет моды из файлов `.mcmod`, `.zip` или `.dll` |
| `mod set <mod>` | Меняет манифест мода |
| `mod remove <mod>...` | Удаляет моды из инстанса |
| `mod enable <mod>... \| --all` | Включает моды |
| `mod disable <mod>... \| --all` | Отключает моды без удаления |
| `mod path [<mod>]` | Выводит путь к папке мода или ко всей папке модов инстанса |
| `loader versions` | Список версий LeviLamina, доступных для версии игры |
| `loader install [<version>]` | Устанавливает LeviLamina в инстанс или меняет её версию |
| `loader remove` | Удаляет LeviLamina из инстанса |
| `world list [<filter>]` | Список миров инстанса и игрока |
| `world import <file.mcworld>...` | Импортирует миры из файлов `.mcworld` |
| `world export <world>...` | Экспортирует миры (создаёт резервную копию) в файлы `.mcworld` |
| `world copy <world>...` | Копирует миры в другой инстанс |
| `world rename <world> <new-name>` | Меняет отображаемое имя мира |
| `world get <world> [<key>[/<sub>...]]` | Читает настройки мира из `level.dat` |
| `world set <world> <key>[/<sub>...]=<value>...` | Меняет настройки мира в `level.dat` |
| `world remove <world>...` | Безвозвратно удаляет миры |
| `pack list [<filter>]` | Список наборов ресурсов, параметров и скинов |
| `pack import <file.mcpack\|file.mcaddon>...` | Устанавливает паки и аддоны из файлов `.mcpack` и `.mcaddon` |
| `pack copy <pack>... \| --all` | Копирует паки в другой инстанс |
| `pack remove <pack>...` | Удаляет установленные паки |
| `screenshot list` | Список скриншотов инстанса и игрока (сначала новые) |
| `screenshot remove <name\|path>... \| --all` | Удаляет скриншоты |
| `server list [<filter>]` | Список сохранённых серверов с проверкой их доступности в сети |
| `player list` | Список профилей игроков инстанса GDK |
| `backup list [<instance>]` | Список резервных копий инстансов и миров (предварительная функция) |
| `backup create [<instance>]` | Создаёт резервную копию игровых данных и модов инстанса (предварительная функция) |
| `backup restore [<instance>] <archive.zip>` | Восстанавливает инстанс из резервной копии (предварительная функция) |

### Поиск того, что установить

| Команда | Что делает |
| --- | --- |
| `installer search [<version>]` | Показывает сборки Minecraft, доступные для установки |
| `installer download <version>` | Скачивает установщик сборки, не устанавливая её |
| `installer list` | Показывает скачанные установщики, включая незавершённые загрузки |
| `installer remove <version\|file>...` | Удаляет скачанные установщики, чтобы освободить место |
| `installer mirrors <version>` | Проверяет скорость зеркал загрузки сборки GDK |
| `curseforge search [<words>]` | Ищет в CurseForge миры, аддоны, паки и скины (сокращение существительного: `cf`) |
| `curseforge show <id>` | Показывает проект CurseForge |
| `curseforge categories` | Показывает классы и категории CurseForge для фильтрации |
| `curseforge install <id>` | Скачивает файл с CurseForge и импортирует его в инстанс |

### Этот ПК и лаунчер

| Команда | Что делает |
| --- | --- |
| `process list` | Показывает запущенные процессы Minecraft, в том числе запущенные вне лаунчера (сокращение: `ps`) |
| `process stop [<instance>\|<pid>...]` | Принудительно закрывает Minecraft (прогресс с последнего автосохранения теряется) |
| `account status` | Показывает вошедший аккаунт Microsoft и принадлежащие ему издания |
| `account login` | Входит в аккаунт Microsoft или меняет его |
| `account logout` | Выходит из аккаунта Microsoft в лаунчере |
| `config list` | Показывает настройки и папки лаунчера |
| `config get <key>` | Выводит значение настройки |
| `config set <key> <value>` | Меняет настройку |
| `config unset <key>` | Сбрасывает настройку к значению по умолчанию |
| `cache clean [packages\|downloads\|partial]...` | Очищает кэш и освобождает место |
| `doctor [--fix [<fix>...]]` | Проверяет компоненты, нужные Minecraft и модам на этом ПК; `--fix` устраняет проблемы (`vcruntime`, `gameinput`, `loader-migration`, `developer-mode`) |
| `self-update` | Обновляет LeviLauncher до последнего релиза |
| `version` | Выводит информацию о версии |
| `help [<command>...]` | Показывает справку по любой команде с примерами |

Вместо любого глагола `list` можно писать `ls`, а вместо `remove` — `rm`. Настройки, которыми управляет `config`, перечислены в разделе [Все настройки](./settings#command-line-keys).

### Версии и пакеты

- `<version>` в командах `install` и `installer` — это сборка из `installer search`: точная версия (`1.21.50.07`), префикс через точку (`1.21.50` означает последнюю `1.21.50.x`; `1.21.5` ей не соответствует) или `latest`. `<file>` — локальный файл `.msixvc`, `.appx`, `.msix`, `.appxbundle` или `.msixbundle`.
- `<package>` в команде `mod install` — это `owner/repo`, `github.com/owner/repo` или URL, при необходимости с `#variant` и `@version`.

## Глобальные флаги

Эти флаги работают со всеми командами:

| Флаг | Значение |
| --- | --- |
| `-i`, `--instance <name>` | Целевой инстанс |
| `-p`, `--player <id\|gamertag>` | Профиль игрока в инстансах GDK |
| `--json` | Машиночитаемый вывод в stdout |
| `-q`, `--quiet` | Выводить только идентификаторы, без прогресса и уведомлений |
| `-v`, `--verbose` | Подробный вывод и журнал лаунчера в stderr |
| `-y`, `--yes` | Автоматически отвечать «да» на запросы подтверждения |
| `--no-input` | Не запрашивать ввод у пользователя |
| `-h`, `--help` | Показать справку по команде |
| `--version` | Вывести версию |

**Какой инстанс:** заданный через `-i`, иначе из переменной окружения `LEVILAUNCHER_INSTANCE`, иначе инстанс по умолчанию (`use`), иначе единственный имеющийся инстанс. **Какой игрок:** заданный через `-p`, иначе из `LEVILAUNCHER_PLAYER`, иначе единственный профиль, иначе профиль вошедшего аккаунта.

## Вывод

- Результаты выводятся в stdout. Прогресс, уведомления и ошибки направляются в stderr; ошибка имеет вид `error:` с подсказкой `hint:` и кодом, например `[ERR_GAME_RUNNING]`.
- Флаг `--json` выводит один JSON-документ: массив для списков и объект в остальных случаях. Ключи записываются в camelCase, время — в формате RFC 3339, размеры — в байтах.
- Флаг `-q` выводит только идентификаторы, по одному на строку.

## Коды возврата

| Код | Значение |
| --- | --- |
| 0 | Успешно |
| 1 | Ошибка |
| 2 | Неверное использование команды |
| 3 | Не найдено |
| 4 | Конфликт (например, игра уже запущена) |
| 5 | Ошибка входа или лицензии |
| 6 | Ошибка сети |
| 7 | Выполнено частично |
| 8 | Требуется изменение системы или права администратора |
| 9 | Превышено время ожидания |
| 10 | Отменено |
| 130 | Прервано (Ctrl-C) |

Команда `launch --wait-exit` возвращает собственный код завершения игры.

## Параметры окна

Эти аргументы открывают окно программы вместо выполнения консольной команды:

| Аргумент | Действие |
| --- | --- |
| `--launch=<instance>` | Открывает лаунчер и запускает указанный инстанс (используется ярлыками на рабочем столе). Если лаунчер уже открыт, инстанс запускается в нём. |
| `--debug` | Дополнительно открывает окно консоли с журналом лаунчера (также поддерживаются `debug`, `-debug` и `/debug`). |
