# Инструменты для миров

В LeviLauncher встроены утилиты для защиты и проверки миров.

## Основные инструменты для миров

- экспорт мира в виде резервной копии, например в файл `.mcworld`
- проверка сведений о мире
- редактирование отдельных полей `level.dat`
- более безопасное переименование мира средствами лаунчера

## Когда делать резервную копию мира

Всегда создавайте резервную копию перед тем, как:

- тестировать версии Minecraft Preview
- устанавливать или обновлять сразу несколько модов
- менять важные метаданные мира
- переносить мир между конфигурациями с сильно отличающимися настройками

## Редактирование `level.dat`

LeviLauncher может открывать доступ к отдельным полям `level.dat` для более удобного редактирования.

::: warning Редактируйте осторожно
В `level.dat` хранятся критически важные метаданные мира. Сначала создайте резервную копию и меняйте только те параметры, назначение которых вам понятно.
:::

## Рекомендуемый порядок резервного копирования

1. Создавайте резервную копию перед крупными обновлениями.
2. Создавайте резервную копию перед добавлением новых модов или паков.
3. Храните хотя бы одну резервную копию вне рабочего пространства версии.
