# Управление версиями

LeviLauncher воспринимает каждую установленную сборку как отдельную версию, которой можно управлять независимо. В приложении установленные версии называются инстансами и отображаются на странице **Инстансы**.

## Что вы можете делать

=== "Windows"

    - устанавливать сборки Minecraft Release или Preview
    - давать версиям понятные имена
    - быстро запускать выбранную версию
    - удалять ненужные версии
    - открывать настройки конкретной версии
    - создавать на рабочем столе ярлык для версии

=== "Android"

    - импортировать официальные APK Minecraft и запускать их прямо в лаунчере, не устанавливая каждую версию в систему
    - хранить несколько версий и их данные отдельно друг от друга
    - выбирать, какую версию открывать с экрана запуска

## Minecraft Release против Preview <Badge platform="windows" />

| Тип | Лучше всего подходит для | Примечания |
| --- | --- | --- |
| Release | Стабильной повседневной игры | Рекомендуется большинству игроков |
| Preview | Тестирования будущих изменений | Повышенный риск повреждения миров, наборов или модов |

## Объяснение изоляции

=== "Windows"

    Изоляция доступна для версий GDK, а также для версий UWP x64 начиная с 1.19.70.2. При включённой изоляции LeviLauncher хранит управляемые данные игры в отдельном рабочем пространстве версии, а не в общей стандартной папке для всех сборок.

    Изоляция пригодится, если вы хотите:

    - использовать разные наборы контента для разных версий
    - безопасно тестировать моды или сборки Minecraft Preview
    - снизить риск того, что одна сборка повлияет на другую

=== "Android"

    Включите изоляцию для импортированной версии, чтобы отделить её миры, наборы и настройки от версии из Google Play. Кроме того, импортированным версиям изоляция часто необходима для запуска.

## Общие задачи управления версиями <Badge platform="windows" />

### Установка новой версии

Установите версию на странице **Скачать**, а по завершении установки вернитесь на страницу **Запуск**.

Переключатель **Установить LeviLamina** на странице установки по умолчанию включён; отключите его, если хотите установить игру без LeviLamina. Эта опция работает только для версий, которые поддерживает LeviLamina.

### Переименование версии

На странице **Инстансы** или **Настройки инстанса** задайте сборке имя, отражающее её назначение, например `Release Выживание` или `Preview Тест`.

### Удаление версии

Удаляйте ненужные версии, особенно неактуальные тестовые сборки Minecraft Preview.

::: warning Будьте осторожны перед удалением
Вместе с версией может удалиться и её управляемая среда. Предварительно создайте резервные копии важных миров.
:::

### Создание ярлыка на рабочем столе

Чтобы запускать нужную версию напрямую, выберите пункт **Создать ярлык экземпляра на рабочем столе** в меню рядом с кнопкой **Запуск**.

## Рекомендуемая стратегия управления версиями <Badge platform="windows" />

- одна изолированная версия Minecraft Release для обычной игры
- одна изолированная версия Minecraft Preview (только при необходимости)
- одна временная тестовая версия для проверки модов или устранения неполадок
