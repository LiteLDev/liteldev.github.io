# Моды и интеграции

LeviLauncher поддерживает работу с модами за пределами возможностей базового лаунчера.

## Доступные возможности

=== "Windows"

    - импорт пакетов модов (`.mcmod`)
    - поддержка пакетов `.zip` и отдельных модов `.dll` — выберите **Все файлы (\*.\*)** в окне выбора файлов
    - включение и отключение установленных модов
    - удаление ненужных модов
    - поиск и скачивание контента через CurseForge
    - установка пакетов LIP встроенным менеджером пакетов, совместимым с [lip](https://github.com/LiteLDev/lip)
    - настройка модов для LeviLamina

    ::: warning Продвинутая область
    Моды, загрузчики и пакетные интеграции легко теряют совместимость, особенно в сборках Minecraft Preview. Эта функциональность рассчитана на опытных пользователей — тестируйте изменения с осторожностью.
    :::

=== "Android"

    - загрузка в игру нативных модов (библиотек `.so`)
    - хранение сборок с модами в изолированных версиях

    Создаёте нативные моды? См. [Android native mods](https://levimc.org/LeviLamina/developer_guides/android/) в документации LeviLamina (на английском).

## Рекомендуемый рабочий процесс для модов

1. Начните с чистой изолированной версии.
2. Убедитесь, что она успешно запускается без модов.
3. Добавляйте по одному моду или небольшой группе модов за раз.
4. Проверяйте запуск игры после каждого изменения.
5. Делайте резервные копии важных миров.

## CurseForge <Badge platform="windows" />

Встроенный каталог и работа с пакетами CurseForge позволяют находить совместимые моды прямо в приложении.

Это удобно, когда нужны:

- наглядный поиск модов
- понятный список совместимых файлов проекта
- минимум ручного поиска за пределами лаунчера

## lip и LeviLamina <Badge platform="windows" />

В LeviLauncher встроен менеджер пакетов, совместимый с [lip](https://github.com/LiteLDev/lip), поэтому отдельно устанавливать lip или среду выполнения .NET не нужно. Он работает так же, как lip: каждая версия хранит свои пакеты в `.lip/state.json`, а сами пакеты читаются из `lip.toml` (старые пакеты, в которых есть только `tooth.json`, по-прежнему работают). Версии, куда LeviLamina или пакеты LIP были установлены через старый лаунчер (`tooth_lock.json`), автоматически переносятся при первой операции с пакетами. Когда включён параметр **Использовать зеркала**, пакеты с GitHub скачиваются через **Прокси GitHub** из [настроек](./settings-personalization); иначе лаунчер подключается к GitHub напрямую (через системный прокси, если он задан). Ранее сохранённый прокси GitHub или `github_proxy` из `config.toml` самого lip (в `%APPDATA%\lip`, например заданный командой `lip config set github_proxy <URL>`) применяется в обоих случаях. Кнопка **Очистить кэш** удаляет скачанные файлы пакетов.

Начиная с lip v0.40, каждая запись в `lip.toml` и `.lip/state.json` указывает целевое окружение ключами `side` (`server` или `client`) и `platform` (идентификатор среды выполнения .NET, например `win-x64`); в lip v0.39 и более ранних версиях эти ключи назывались `platform` и `runtime`. Файл `.lip/state.json` со старыми ключами, созданный в lip v0.39 и ниже или в старом лаунчере, автоматически обновляется перед следующей операцией с пакетами: `platform` переименовывается в `side`, а `runtime` — в `platform`. Если lip всё же не может прочитать файл, операция отклоняется с подсказкой: переименуйте `platform` в `side`, а `runtime` — в `platform`, либо переустановите пакеты этой версии.

Эти инструменты рассчитаны на опытных пользователей, которые собирают конфигурации модов на базе менеджеров пакетов и загрузчиков.

Рекомендации:

- начинайте со стабильных релизных версий Minecraft (Release)
- не меняйте слишком много параметров одновременно
- записывайте точный номер версии, на которой всё успешно заработало

О том, как установить LeviLamina на клиент, см. в разделе [Install client on Windows](https://levimc.org/LeviLamina/user_guides/install_on_client/) документации LeviLamina (на английском).

### Страница LeviMC Mods

На странице **LeviMC Mods** собраны моды с [levimc.org/mods](https://levimc.org/mods/), у которых есть клиентская сборка для Windows x64 (запись с `side = "client"` и `platform = "win-x64"`). Их можно искать по названию, ID, автору, тегу или описанию; сортировать по релевантности, звёздам, дате обновления или новизне; фильтровать по версии игры, версии LeviLamina, тегам (рекомендуемые теги вроде «Библиотека / API» или «Экономика» идут первыми; любой тег можно также исключить), лицензии (по группе вроде «Разрешительная» или по SPDX ID), зависимостям и автору (**Ещё от …** на странице мода). При установке мода выбирается его вариант `client`, при его отсутствии — вариант по умолчанию, иначе — первый другой вариант с клиентской сборкой; на странице мода можно выбрать любой из этих вариантов вручную. Кнопка **Install with LeviLauncher** на странице мода на levimc.org содержит ссылку вида `levilauncher://install/<mod id>?version=<version>`, которая запускает установку указанной версии мода в LeviLauncher.

## Нативные моды <Badge platform="android" />

Нативные моды выполняют нативный код в процессе игры. Устанавливайте моды только из надёжных источников и сначала проверяйте их в изолированной версии.

О том, как создать свой мод, читайте в разделе [Android native mods](https://levimc.org/LeviLamina/developer_guides/android/) документации LeviLamina (на английском языке).

## Если что-то сломалось после добавления модов

- сначала отключите самый новый (newest) мод
- сравните работу игры с последней заведомо исправной версией
- перед дальнейшим тестированием перенесите важные миры в безопасное место
- перейдите к разделу [Обновление и устранение неполадок](./update-troubleshooting)
