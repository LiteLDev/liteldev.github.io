# 设置与个性化

LeviLauncher 提供了完善的设置页，用于调整路径、外观、包管理、隐私偏好与更新策略。

## 主要设置分区

当前设置主要分为以下几个区域：

- 基础设置
- 个性化
- 包管理
- 其他设置
- 隐私
- 软件更新
- 关于

## 你可以调整什么

### 路径与存储

- 基础内容路径
- 托管文件所在的可写位置
- 契合磁盘布局的环境存放方式

### 外观

- 语言
- 明暗主题偏好
- 主题色行为
- 背景与视觉个性化项

#### 背景图片与界面材质

先在 **个性化 → 壁纸 → 背景图片** 中选择图片文件夹，再到 **个性化 → 材质与可读性** 中调整 **界面材质**（即壁纸与内容之间的图层）。导航栏、卡片、标签页、表单控件和浮层共用一套材质参数。日间和夜间材质分别保存，并随当前主题自动应用；材质设置中的 **日间模式** / **夜间模式** 按钮仅用于切换当前编辑和预览的配置。

| 设置 | 用途 |
| --- | --- |
| 均衡 | 默认预设：柔和磨砂并开启可读性保护 |
| 通透 | 让更多图片细节透过卡片，关闭可读性保护，适合简单、低反差的背景 |
| 纯色 | 卡片完全不透明并关闭卡片磨砂，背景仅在卡片外显示 |
| 界面不透明度 | 统一调节中性界面底色，文字、图标和按钮不会随之变透明 |
| 界面磨砂 | 统一调节面板、导航与浮层后方的模糊程度；图片模糊则作用于整张背景 |
| 背景遮罩 | 日间用浅色、夜间用深色柔化背景，效果不同于图片亮度和图片不透明度 |
| 可读性保护 | 根据主题、图片亮度、不透明度和模糊量设置保守的界面底色下限，并加深次要文字 |

实时预览与主界面共用当前加载的图片及渲染参数。当可读性保护提高了卡片的实际不透明度时，设置界面会显示实际生效的值；该计算既不分析图片内容，也不上传图片。**重置当前主题** 仅恢复当前正在编辑的材质配置，不会清除图片文件夹或另一主题的配置。

文件夹内有多张图片时，可点击 **换一张** 切换。**顺序** 模式按文件名自然排序，**随机** 模式则会避免连续抽中当前图片。未选择图片、图片无法加载或图片不透明度为 0 时，界面会恢复为普通材质。当系统要求高对比度、减少透明效果或不支持背景磨砂时，界面会回退为纯色。

### 包管理

- 内置包管理器（兼容 [lip](https://github.com/LiteLDev/lip)，无需安装或更新）：软件包下载失败时，可通过 **清理缓存** 删除已下载的软件包文件
- **使用镜像源**：从中国大陆镜像源下载启动器更新、软件包和版本列表（中国大陆用户默认开启）
- 下载软件包时使用的 **GitHub 代理**（开启 **使用镜像源** 时显示）：可选择预设，或选择 **自定义** 填写代理地址；留空即恢复默认值

### 隐私

- 使用情况统计（Google Analytics），可随时关闭
- Google Analytics 服务条款与 Google 隐私政策链接

### 更新

- 更新检查
- **接收测试版更新**：获取启动器预发布版本

## 推荐默认值

- 将托管文件放在可写且空间充足的磁盘位置
- 除非你想使用启动器预发布版本，否则请保持 **接收测试版更新** 关闭
- 待基础环境稳定后，再微调外观

## 什么时候值得重新检查设置

遇到以下情况时，建议重新检查设置：

- 打算将安装目录迁移到另一块磁盘
- 遇到写入权限错误
- 需要在不同设备上使用不同的外观或路径策略
- 需要排查下载或组件识别问题
