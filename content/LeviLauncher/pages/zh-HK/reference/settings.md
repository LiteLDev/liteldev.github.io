# 全部設定

本頁按分頁列出 Windows 版 **設定** 頁面的每一項設定（以 LeviLauncher 1.1.0 為準）；可在[命令列](./command-line)中修改的項目，會一併列出對應的 `config` 鍵。你可以用頁面頂部的搜尋框按名稱尋找設定。至於應如何調整，請參閱[設定與個人化](../guide/settings-personalization)。

## 基礎設定

| 設定 | 作用 | 鍵 |
| --- | --- | --- |
| **內容路徑 → 根目錄** | 資料根目錄：存放實例、下載和備份的資料夾（見[資料夾與檔案](./files)）。按 **套用** 儲存新資料夾，按 **恢復預設** 還原為預設位置。下方會顯示 **安裝器目錄** 和 **實例目錄**。已有資料不會隨之移動。 | `data-root` |
| **語言** | 啟動器的介面語言。 | — |
| **Discord 遊戲狀態** | 在 Discord 上顯示你的遊戲狀態。預設開啟。 | `discord` |
| **Minecraft 啟動時** | Minecraft 啟動時啟動器的動作：**最小化啟動器**（預設）、**隱藏到系統匣**、**關閉啟動器** 或 **保持啟動器開啟**。 | `on-game-launch` |
| **Minecraft 關閉時** | Minecraft 關閉時啟動器的動作：**重新打開啟動器**（預設）、**保持原樣** 或 **關閉啟動器**。 | `on-game-exit` |
| **關閉視窗時隱藏到系統匣** | 按下關閉按鈕時將啟動器隱藏到系統匣而非結束程式；最小化按鈕則仍會最小化到工作列。預設關閉。 | `close-to-tray` |

## 個性化

此分頁分為四部分。個性化設定（顏色、不透明度等）會按日間和夜間主題分別儲存（**按模式分別設定**），可選擇 **日間模式** 或 **夜間模式** 分別編輯。

### 主題與配色

| 設定 | 作用 |
| --- | --- |
| **外觀模式** | **日間模式**、**夜間模式**、**手動設置時間**（在 **夜間模式開始時間** 與 **夜間模式結束時間** 之間使用夜間模式）、**日出日落**（根據本地日出日落時間切換，在裝置上計算）或 **跟隨系統**（跟隨 Windows 設定）。 |
| **主題色** | 強調色：從 **預设顏色**、**更多顏色** 中選擇，或使用 **自定義顏色**。 |
| **底色模式** | 在背景圖片下方加一層純色以增強對比度：**無**、**跟隨主題色** 或 **自定義顏色**，並可調整 **底色不透明度**。 |

### 版面與動效

| 設定 | 作用 |
| --- | --- |
| **使用頂部導航欄** | 以頂部導航欄取代垂直側邊欄。 |
| **停用動畫** | 關閉介面的過渡動畫。 |

### 桌布

| 設定 | 作用 |
| --- | --- |
| **背景圖片** | 用作背景的圖片資料夾：**選擇圖片**、**開啟資料夾**、**清除圖片**；資料夾內有多張圖片時可按 **換一張**。 |
| **適應方式** | **智能**、**居中**、**適應**、**拉伸**、**平鋪**、**左上** 或 **右上**。 |
| **播放順序** | **亂序** 或 **順序**（按檔案名稱的自然順序）。 |
| **背景模糊**、**背景亮度**、**背景不透明度** | 調整圖片的顯示效果。 |

### 材質與可讀性

| 設定 | 作用 |
| --- | --- |
| **介面材質** | 導航、卡片、分頁、控制項和彈出層疊在桌布上的外觀。**材質預設**：**均衡**（預設）、**通透** 或 **純色**。 |
| **介面不透明度**、**介面模糊**、**背景遮罩** | 微調材質效果。 |
| **可讀性保護** | 根據主題、圖片亮度和模糊程度設定最低的表面著色，確保文字清晰易讀。 |
| **重設目前主題** | 還原正在編輯的主題材質。 |

各項設定的詳細說明見[設定與個人化](../guide/settings-personalization#桌布與介面材質)。

## 套件管理

| 設定 | 作用 | 鍵 |
| --- | --- | --- |
| **清理快取** | 刪除套件管理器已下載的套件檔案；於套件下載失敗時使用。 | `cache clean packages` |
| **使用鏡像來源** | 從中國內地的鏡像下載啟動器更新、套件和版本列表。中國內地用戶預設開啟。 | `mirror` |
| **GitHub 代理** | 下載套件時使用的 GitHub 代理，在開啟 **使用鏡像來源** 時顯示：可選擇預設項目，或選擇 **自訂** 輸入 URL。留空則恢復預設值（`https://gh-proxy.org/https://github.com`）。 | `github-proxy` |

## 其他設定

| 設定 | 作用 |
| --- | --- |
| **進程管理 → 掃描進程** | 列出正在執行的 Minecraft 程序；按 **結束** 結束單一程序，按 **結束所有進程** 結束全部。未儲存的遊戲進度可能會遺失。 |
| **實驗性功能 → 實例備份（實驗性）** | 在 **實例設定** 中加入備份與還原功能。開啟時會先顯示警告。 |

## 私隱

| 設定 | 作用 |
| --- | --- |
| **使用情況統計（Google Analytics）** | 傳送使用情況統計資料以協助改進啟動器；可隨時關閉。附有 **Google Analytics 服務條款** 和 **Google 私隱政策** 的連結。 |

## 軟體更新

| 設定 | 作用 | 鍵 |
| --- | --- | --- |
| **接收測試版更新** | 同時接收啟動器的預發佈更新。預設關閉。 | `beta-updates` |

顯示啟動器的版權資訊，以及 LiteLDev 的 GitHub 和 Discord 社群連結。

## 命令列鍵 {#command-line-keys}

`LeviLauncher.exe config list` 會顯示每個鍵的值及其來源：`set`（已儲存）、`default`（預設）、`auto`（自動偵測）或 `lip`（來自 lip 本身的 `config.toml`）。使用 `config set <key> <value>` 修改鍵值，使用 `config unset <key>` 則將其還原為預設值。

| 鍵 | 取值 | 含義 |
| --- | --- | --- |
| `data-root` | 資料夾路徑 | 實例、下載和備份的存放位置（已有資料不會隨之移動） |
| `default-instance` | 實例名稱 | 指令未指定實例時使用的實例（與 `use` 相同） |
| `mirror` | `on`、`off` | 從中國內地的鏡像下載（未設定時按地區自動判斷） |
| `github-proxy` | http(s) URL | 下載模組時使用的 GitHub 代理（開啟鏡像或已明確設定時生效） |
| `beta-updates` | `on`、`off` | 接收啟動器的預發佈更新（預設 `off`） |
| `discord` | `on`、`off` | 遊玩時顯示 Discord 遊戲狀態，僅適用於啟動器視窗（預設 `on`） |
| `on-game-launch` | `minimize`、`hide`、`close`、`keep` | 遊戲啟動時啟動器視窗的動作（預設 `minimize`） |
| `on-game-exit` | `reopen`、`keep`、`close` | 遊戲結束時啟動器視窗的動作（預設 `reopen`） |
| `close-to-tray` | `on`、`off` | 關閉啟動器視窗時保留在系統匣中（預設 `off`） |

以下唯讀鍵可透過 `config list` 和 `config get` 查看：`instances-dir`、`installers-dir`、`backups-dir`、`cache-dir`、`logs-dir`（即[資料夾與檔案](./files)所列的資料夾）以及 `config-file`（設定檔 `%APPDATA%\LeviLauncher\config.json`）。
