# 設定與個人化

LeviLauncher 的設定頁面可用於調整路徑、外觀、套件管理、私隱偏好與更新策略。

## 主要設定分區

應用程式的設定分為以下幾個區域：

- 基礎設定
- 個性化
- 套件管理
- 其他設定
- 私隱
- 軟體更新
- 關於

## 你可以調整什麼

### 路徑與儲存

- 基礎內容路徑
- 託管檔案的可寫入儲存位置
- 配合磁碟佈局的環境放置方式

### 外觀

- 語言
- 淺色/深色主題偏好
- 主題色行為
- 背景與視覺個人化選項

#### 桌布與介面材質

先在 **個性化 → 桌布 → 背景圖片** 中選擇圖片資料夾，再到 **個性化 → 材質與可讀性** 中調整 **介面材質**（即桌布與內容之間的一層）。導覽列、卡片、分頁、表單控制項和彈出層共用同一套材質系統。日間與夜間材質會分開儲存，並隨應用程式主題自動切換；材質編輯器中的 **日間模式** / **夜間模式** 按鈕僅用於選擇要編輯和預覽的設定檔。

| 設定 | 作用 |
| --- | --- |
| 均衡 | 預設方案：柔和磨砂效果，並開啟可讀性保護 |
| 通透 | 讓卡片透出更多桌布細節，並關閉可讀性保護；適合簡單、低對比度的圖片 |
| 純色 | 卡片完全不透明且不使用模糊效果；卡片以外區域仍會顯示桌布 |
| 介面不透明度 | 調整中性介面底色，文字、圖示和按鈕不會隨之變淡 |
| 介面模糊 | 控制面板、導覽列與彈出層後方的模糊程度；圖片模糊則影響整張桌布 |
| 背景遮罩 | 日間模式以淺色、夜間模式以深色柔化桌布，與圖片亮度及不透明度分開調整 |
| 可讀性保護 | 根據主題、亮度、圖片不透明度與模糊程度套用保守的最低底色，並強化次要文字 |

即時預覽與主視窗共用已載入的圖片及渲染參數。當可讀性保護拉高了卡片的實際不透明度時，編輯器會顯示實際套用的數值。這項計算不會分析或上傳圖片。**重設目前主題** 只會還原正在編輯的材質設定檔，不會清除圖片資料夾或另一個主題的設定檔。

當資料夾內有多張圖片時，可使用 **換一張** 切換。**順序** 模式按檔案名稱自然排序，**亂序** 模式則會避免重複抽選目前的圖片。若未選取圖片、圖片無法載入或圖片不透明度為 0，介面會恢復為一般表面。當系統要求高對比度、減少透明效果或不支援背景濾鏡時，介面會改用純色後備表面。

### 套件管理

- 內置套件管理器（相容 [lip](https://github.com/LiteLDev/lip)，毋須另外安裝或更新）：套件下載失敗時，可透過 **清理快取** 刪除已下載的套件檔案
- **使用鏡像來源**：從中國大陸的鏡像來源下載啟動器更新、套件和版本清單（中國大陸使用者預設開啟）
- 下載套件時使用的 **GitHub 代理**（開啟 **使用鏡像來源** 時顯示）：可選擇預設項目，或選擇 **自訂** 輸入自己的網址；留空即可恢復預設值

### 私隱

- 使用情況統計（Google Analytics），可隨時關閉
- Google Analytics 服務條款與 Google 私隱政策連結

### 更新

- 更新檢查
- **接收測試版更新**：開啟後可取得啟動器預發佈版本

## 建議預設值

- 將託管檔案存放在可寫入且空間充足的磁碟位置
- 除非你想使用啟動器預發佈版本，否則請保持關閉 **接收測試版更新**
- 先確保基礎環境穩定，再微調外觀設定

## 什麼時候值得重新檢查設定

遇到以下情況時，建議返回設定頁面檢查：

- 想將安裝檔案遷移至另一塊磁碟
- 遇到寫入權限錯誤
- 想在不同裝置上使用不同的外觀或路徑策略
- 需要排查下載或組件識別問題
