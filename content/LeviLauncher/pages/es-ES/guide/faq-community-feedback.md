# Preguntas frecuentes, comunidad y comentarios

## Preguntas frecuentes

### ¿Es obligatorio tener la versión original de Minecraft Bedrock?

Sí. LeviLauncher está diseñado para usarse con **Minecraft Bedrock Edition (GDK / UWP) original**.

### ¿Se puede usar en macOS o Linux?

LeviLauncher cuenta con versiones para **Windows** y **Android** ([guía de Android](/es-ES/guide/version-management?platform=android)). No existen versiones para macOS ni Linux.

### ¿Hay una versión para iOS?

No. No tenemos previsto desarrollar una versión de LeviLauncher para iOS.

### ¿Debería elegir Release o Preview?

Para jugar a diario, prioriza la versión **Lanzamiento** (Release) de Minecraft. Usa la versión **Vista previa** (Preview) solo si necesitas probar contenido futuro de forma expresa y estás dispuesto a asumir su inestabilidad.

### ¿Es obligatorio el aislamiento?

No es obligatorio, pero sí muy recomendable para entornos de prueba, versiones de vista previa (Preview) de Minecraft y entornos con Mods. El aislamiento está disponible para las versiones GDK y para las versiones UWP x64 1.19.70.2 o posteriores.

### ¿Se pueden gestionar mundos y paquetes de recursos en el lanzador?

Sí. LeviLauncher incluye vistas de contenido para mundos, paquetes de recursos, paquetes de comportamiento, paquetes de skins, capturas de pantalla y listas de servidores.

### ¿Se pueden instalar Mods?

Sí, pero es un procedimiento avanzado. Te recomendamos empezar con una versión aislada limpia e ir probando poco a poco.

### ¿Puedo usar LeviLauncher desde la línea de comandos?

Sí, en Windows. Si ejecutas `LeviLauncher.exe` sin argumentos, se abrirá la ventana del programa; si le pasas un comando como `install latest`, `play`, `instance list` o `mod install <mod>`, se ejecutará en la terminal y finalizará. Ejecuta `LeviLauncher.exe help` para ver todos los comandos y `LeviLauncher.exe help <comando>` para consultar las opciones y ejemplos de un comando concreto.

### ¿Qué necesita la versión para Android?

Android 9.0 o posterior en un dispositivo ARM64 y Minecraft Bedrock Edition 1.21.80 o posterior instalado desde Google Play. Consulta [Instalación](../install?platform=android).

### ¿Puedo ejecutar varias versiones de Minecraft en Android?

Sí. Puedes importar archivos APK oficiales de Minecraft para ejecutar otras versiones desde el lanzador y activar el aislamiento para mantener sus datos por separado.

## Cómo informar de problemas y sugerencias de funciones

Usa [GitHub Issues](https://github.com/LiteLDev/LeviLauncher/issues) para enviar:

- Errores reproducibles
- Problemas de instalación claramente relacionados con LeviLauncher
- Sugerencias para mejorar la claridad de la documentación
- Solicitudes de nuevas funciones con un caso de uso claro

Para problemas de la versión de Android, acude a [LiteLDev/LeviLauncher-Android Issues](https://github.com/LiteLDev/LeviLauncher-Android/issues).

## Antes de enviar un Issue, se recomienda

- Actualizar a la última versión disponible
- Comparar el comportamiento en una versión aislada limpia
- Desactivar temporalmente los Mods o paquetes de recursos añadidos recientemente
- Anotar los pasos exactos para reproducir el problema
