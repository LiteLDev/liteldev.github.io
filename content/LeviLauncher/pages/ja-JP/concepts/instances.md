# インスタンスとゲームバージョン

LeviLauncher は Minecraft の各コピーを**インスタンス**としてインストールします。インスタンスとは、固有の名前と設定、そして必要に応じて独立したゲームデータを持つ 1 つのゲームバージョンです。バージョンが同じかどうかにかかわらず、複数のインスタンスを共存させて必要なものを起動できます。アプリ内では **インスタンス** ページに一覧表示されます。

## インスタンスとは

=== "Windows"

    インスタンスの実体は、ランチャーの `Instances` フォルダー内にあるフォルダーです（[フォルダーとファイル](../reference/files)を参照）。このフォルダー名がそのままインスタンスの名前になり、中には次のものが入っています。

    - インストーラーから展開した、Minecraft の 1 つのビルドのゲームファイル
    - `.levilauncher\instance.json`: ランチャーが記録しているインスタンスの情報（ゲームバージョン、チャンネル、独自のゲームデータを持つかどうか、およびコンソール・エディターモード・起動引数・環境変数などの起動オプション）
    - `mods\`: インスタンスの Mod。`.lip\`: 内蔵パッケージマネージャーでインストールしたパッケージの状態（[Mod の読み込み](./mod-loading)を参照）
    - [隔離](./isolation)が有効なときの、インスタンス独自のゲームデータ（ワールド、パック、設定）

    Mod は常に 1 つのインスタンスに属します。一方、ゲームデータが 1 つのインスタンスに属するのは隔離が有効なときだけで、無効な場合はこの PC で Minecraft が通常使うゲームデータを使用します。

=== "Android"

    インスタンスの実体は、LeviLauncher にインポートした公式の Minecraft APK です。システムにはインストールされず、ランチャーの内部で動作します。デバイスには引き続き Google Play 版の Minecraft（1.21.80 以降）がインストールされている必要があり、インポートしたバージョンと並んで LeviLauncher に表示されます。

    バージョン分離を使うと、インポートしたバージョンのワールド、パック、設定を、インストール済みの Google Play 版から切り離せます。インポートしたバージョンを起動するには、多くの場合この分離が必要です。

## 正式版とプレビュー版

Minecraft のビルドはすべて、いずれか 1 つの**チャンネル**に属します。

| チャンネル | 内容 |
| --- | --- |
| Release（正式版） | ほとんどのプレイヤーが使う安定版のゲーム。 |
| Preview（プレビュー版） | 今後のバージョンのテスト用ビルド。ワールド、パック、Mod が壊れやすくなります。 |
| Beta | UWP 向けにのみ公開されたテストビルド。 <Badge platform="windows" /> |

Windows では、正式版とプレビュー版がそれぞれ専用のゲームデータフォルダー（`Minecraft Bedrock` と `Minecraft Bedrock Preview`）を持つため、隔離していないプレビュー版インスタンスであっても正式版インスタンスとワールドを共有することはありません。

## GDK ビルドと UWP ビルド <Badge platform="windows" />

Windows 版 Minecraft はこれまで 2 つのパッケージ形式で公開されており、LeviLauncher は両方に対応しています。同じバージョンに両方の形式がある場合は GDK が選ばれます。

| | GDK | UWP |
| --- | --- | --- |
| インストーラー | `.msixvc`。LeviLauncher が計測して選んだミラーからダウンロード | `.appx` / `.msix`（またはバンドル）。Windows Update からダウンロード |
| インストールに必要 | Minecraft を所有している、サインイン済みの Microsoft アカウント | — |
| 実行に必要 | Microsoft Gaming Services と Microsoft GameInput | パッケージを Windows に登録するための Windows の開発者モード |
| 共有ゲームデータ | `%APPDATA%\Minecraft Bedrock`（プレビュー版: `Minecraft Bedrock Preview`）。`Users\` の下にプレイヤープロファイルごとに 1 フォルダー | `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState`（プレビュー版: `Microsoft.MinecraftWindowsBeta_8wekyb3d8bbwe`） |
| 隔離 | すべてのバージョン | 1.19.70.2 以降の x64 バージョン |
| LeviLamina | 対応バージョンでは LeviLauncher がインストール | LeviLauncher はインストールしない |
| 起動引数と環境変数 | 対応 | 非対応 |

ローカルからインポートしたインストーラー（`.msixvc`、`.appx`、`.msix`、`.appxbundle`、`.msixbundle`）は、拡張子に応じて GDK または UWP としてインストールされます。

### プレイヤープロファイル {#player-profiles}

GDK インスタンスは、ワールド、スクリーンショット、サーバーリストを**プレイヤープロファイル**ごとに保存します。プレイヤープロファイルは `Users\` の下にあるプレイヤー ID 名のフォルダーで、ランチャーがゲーマータグを把握していればゲーマータグで表示されます。リソースパックとビヘイビアパックはすべてのプロファイルで共有されます（`Users\Shared\`）。スキンパックはゲームのバージョン 1.26 以降では共有されますが、それより前のバージョンではプロファイルごとに保存されます。UWP インスタンスにはプロファイルがありません。

## Windows への登録 <Badge platform="windows" /> {#registration-with-windows}

Windows がインストール済みの Minecraft として認識できるのは、各チャンネルにつき 1 つだけです。インスタンスを**登録**すると、Windows はそれをそのチャンネルの Minecraft として扱い、スタートメニュー、`minecraft://` リンク、Xbox の機能からそのインスタンスが使われるようになります。登録を行うと、正式版またはプレビュー版の枠に現在割り当てられているもの（Microsoft Store のゲームや別のインスタンス）が置き換わりますが、そのデータはそのまま残ります。登録や登録解除によってゲームデータに手が加えられることはありません。

UWP インスタンスは起動時に自動で登録されます。登録済みのインスタンスの名前を変更したり削除したりするには、事前に登録を解除する必要があります。
