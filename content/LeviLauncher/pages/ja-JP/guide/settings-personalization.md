# 設定とカスタマイズ

LeviLauncher には充実した設定ページがあり、パス、外観、パッケージ管理、プライバシー設定、更新方針を調整できます。

## 主な設定セクション

現在、設定は以下のセクションに分かれています：

- 基本設定
- 個人用設定
- パッケージ管理
- その他
- プライバシー
- アップデート
- 情報

## 調整できる項目

### パスとストレージ

- 基本コンテンツパス
- ホストファイルを保存する書き込み可能な場所
- ディスク構成に合わせた環境の配置

### 外観

- 言語
- ライト/ダークテーマの選択
- テーマカラーの動作
- 背景および外観のカスタマイズ項目

#### 壁紙とインターフェイスのマテリアル

**個人用設定 → 壁紙 → 背景画像** で画像フォルダーを選択し、**個人用設定 → マテリアルと読みやすさ** を開いて、壁紙とコンテンツの間にあるレイヤーの **インターフェイスのマテリアル** を調整します。ナビゲーション、カード、タブ、フォームコントロール、ポップアップの各サーフェスは、1 つのマテリアルシステムを共有しています。ライトとダークのプロファイルは個別に保存され、アプリのテーマに合わせて自動的に適用されます。マテリアルエディターの **ライトモード** / **ダークモード** ボタンは、編集・プレビューするプロファイルを切り替えるためのものです。

| 設定 | 動作 |
| --- | --- |
| バランス | 既定のプリセット：読みやすさの保護を有効にしたソフトなガラス調 |
| クリア | カード越しに壁紙がよく透けて見え、読みやすさの保護はオフになります。シンプルでコントラストの低い画像に最適です |
| ソリッド | ぼかしのない不透明なカードになります。カードの外側では壁紙がそのまま見えます |
| インターフェイスの不透明度 | テキスト、アイコン、ボタンを薄くせずに、インターフェイスのニュートラルなサーフェスの色合いを変更します |
| インターフェイスのぼかし | パネル、ナビゲーション、ポップアップの背後のぼかしを調整します。画像のぼかしは壁紙全体に適用されます |
| 壁紙のオーバーレイ | 画像の明るさや不透明度とは別に、ライトモードでは明るい色合い、ダークモードでは暗い色合いを重ねて壁紙を落ち着かせます |
| 読みやすさの保護 | テーマ、明るさ、画像の不透明度、ぼかしに応じて控えめな最小限の色合いを適用し、補助テキストを見やすくします |

ライブプレビューは、読み込まれた画像とレンダリングパラメーターをメインウィンドウと共有します。保護機能によって実際のカードの不透明度が上がると、エディターには適用後の値が表示されます。この計算で画像が解析されたりアップロードされたりすることはありません。**このテーマをリセット** は編集中のマテリアルプロファイルのみを初期状態に戻し、画像フォルダーやもう一方のテーマのプロファイルは消去しません。

フォルダー内に複数の画像がある場合は、**次の画像** を使用できます。**順次** はファイル名の自然順で切り替え、**ランダム** は現在の画像が連続しないように切り替えます。画像が選択されていない場合、画像を読み込めない場合、または画像の不透明度が 0 の場合、インターフェイスは通常のサーフェスに戻ります。ハイコントラスト、透明度の低減が有効な場合や、背景フィルターがサポートされていない環境では、不透明なフォールバックサーフェスが使用されます。

### パッケージ管理

- 内蔵パッケージマネージャー（[lip](https://github.com/LiteLDev/lip) 互換、インストールや更新は不要）：パッケージのダウンロードに失敗する場合に、ダウンロード済みパッケージファイルを削除する **キャッシュを削除**
- **ミラーソースを使用**：ランチャーの更新、パッケージ、バージョン一覧を中国本土のミラーからダウンロードします（中国本土のユーザーはデフォルトで有効）
- パッケージのダウンロードに使う **GitHub プロキシ**（**ミラーソースを使用** がオンのときに表示）：プリセットを選ぶか、**カスタム** を選んで独自の URL を入力します。空欄にすると既定値に戻ります

### プライバシー

- 利用状況の分析（Google Analytics）。いつでもオフにできます
- Google Analytics の利用規約と Google プライバシーポリシーへのリンク

### アップデート

- 更新の確認
- **ベータ版アップデートを受信**：ランチャーのプレリリース版アップデートを受け取ります

## 推奨されるデフォルト値

- ホストファイルは、書き込み可能で十分な空き容量があるディスク上に配置する
- ランチャーのプレリリース版ビルドが必要な場合を除き、**ベータ版アップデートを受信** はオフのままにする
- 外観を細かく調整する前に、まず基本環境を安定させる

## 設定を再確認する価値があるタイミング

次のような場合は、設定ページを確認することをお勧めします：

- インストール先を別のディスクに移行したい場合
- 書き込み権限のエラーが発生した場合
- マシンごとに異なる外観やパス構成を使いたい場合
- ダウンロードやコンポーネントの検出に関する問題をトラブルシューティングする必要がある場合
