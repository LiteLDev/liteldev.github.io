# 更新とトラブルシューティング

LeviLauncher のインストール、更新、起動がうまくいかない場合は、まずこのページを参照してください。

## よくある問題 <Badge platform="windows" />

### ランチャーで Release バージョンが承認されていないと表示される

1 つの Microsoft アカウントで Microsoft Store にサインインできるのは 10 台までで、ランチャーも 1 台のデバイスとしてカウントされます。  
[Microsoft Store のデバイス管理](https://account.microsoft.com/devices/content) で不要なデバイスを削除してください。

### Gaming Services が不足または破損している

- ランチャーの案内に従ってインストールまたは修復を行ってください。
- 必要に応じて、Microsoft Store で Minecraft Bedrock のインストール状態を確認してください。

### GameInput が不足している

- LeviLauncher の画面の指示に従って、必要な redistributable をインストールしてください。
- インストール後、必要に応じてランチャーを再起動してください。

### インストールパスに書き込めない

- **設定 → 基本設定** でホストコンテンツのパスを書き込み可能な場所に変更してください。
- インストール中や自己更新中にランチャーが管理者権限への昇格を求めた場合は、信頼できることを確認したうえでのみ許可してください。

### LeviLauncher がすぐに終了する、またはウィンドウが表示されない

- UI が表示される前にランチャーが終了する場合は、`%LOCALAPPDATA%\LeviLauncher\Logs\startup.log` を確認してください。
- 起動に失敗した場合は一度だけ再試行してください。それでも解決しない場合は、GitHub で Issue を作成する際に `startup.log` を添付してください。

### 特定のバージョンが起動できない

- まず Mod なしでそのバージョンが起動するか試してください。
- 必要な Windows コンポーネントが揃っているか確認してください。
- そのバージョンが完全にインストールされているか確認してください。
- 問題を切り分けるため、クリーンな隔離環境でテストしてみてください。

### ダウンロードが遅い、または繰り返し失敗する

- ミラーを切り替えてください。
- 時間をおいてもう一度試してください。
- 可能であれば、ローカルパッケージソースに切り替えてください。

## Android でのよくある問題 <Badge platform="android" />

### Minecraft が見つからない、または非対応

Google Play から公式の Minecraft アプリ（1.21.80 以降）をインストールまたは更新し、LeviLauncher を開き直してください。

### インポートしたバージョンが起動しない

インポートしたバージョンにはバージョン分離が必要なことがよくあります。インスタンス設定でこれを有効にして再試行してください。

### 起動に失敗する

設定を変更する前に、エラー画面から起動ログを開いて原因を確認してください。

### データの移行

起動時に、ランチャーが古いデータディレクトリを移行することがあります。移行が完了し、ワールド、パック、設定が使えることを確認するまで、古いディレクトリを削除しないでください。

## より安全な回復手順

1. まず重要なワールドをバックアップしてください。
2. 最近追加した Mod やリソースパックを削除してください。
3. クリーンな隔離バージョンを使って比較テストを行ってください。
4. 必要に応じて、問題のあるバージョンを再インストールしてください。

## 自己更新について <Badge platform="windows" />

LeviLauncher はアプリ自身の更新を確認、ダウンロード、インストールできます。インストールディレクトリへの書き込み権限がない環境では、管理者権限が必要になる場合があります。

## Issue を立てるタイミング

次の条件を満たす場合は、GitHub での報告を推奨します：

- 問題を安定して再現できる
- 基本的な回復手順を試しても解決しない
- 一般的な Windows 環境の問題ではなく、LeviLauncher 自体の問題に見える

報告する際は、次の情報を添えてください：

- Windows バージョン
- LeviLauncher バージョン
- 具体的な操作手順
- スクリーンショットまたはログ（ある場合）

問題の報告先：[GitHub Issues](https://github.com/LiteLDev/LeviLauncher/issues)

Android 版の場合は、Android のバージョン、デバイスの機種、起動ログを添えて [LiteLDev/LeviLauncher-Android](https://github.com/LiteLDev/LeviLauncher-Android/issues) に Issue を作成してください。
