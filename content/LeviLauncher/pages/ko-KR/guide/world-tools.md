# 월드 도구

LeviLauncher는 월드 데이터를 보호하고 확인하는 데 유용한 몇 가지 도구를 제공합니다.

## 주요 기능

- 월드를 `.mcworld` 등의 백업 패키지로 내보내기
- 월드 관련 정보 확인
- 일부 `level.dat` 필드 편집
- 런처에서 안전하게 월드 이름 변경

## 언제 월드를 백업해야 하나요?

다음과 같은 작업을 하기 전에는 반드시 월드를 먼저 백업하세요.

- 마인크래프트 프리뷰(Preview) 버전 테스트 전
- 여러 개의 모드를 설치하거나 업데이트하기 전
- 중요한 월드 메타데이터를 수정하기 전
- 호환성 차이가 큰 환경으로 월드를 이전하기 전

## `level.dat` 편집에 관하여

LeviLauncher에서는 `level.dat` 파일의 일부 필드를 간편하게 다룰 수 있도록 표시합니다.

::: warning 신중히 편집하세요
`level.dat`는 민감한 월드 메타데이터입니다. 작업 전에 반드시 백업하고, 역할을 정확히 아는 필드만 수정하세요.
:::

## 권장 백업 습관

1. 주요 버전 업데이트 전에 백업하세요.
2. 새로운 모드나 리소스팩을 추가하기 전에 백업하세요.
3. 현재 버전의 작업 디렉터리 외부에 백업본을 최소 하나 이상 보관하세요.
