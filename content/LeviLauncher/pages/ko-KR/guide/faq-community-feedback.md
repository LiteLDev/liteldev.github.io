# 자주 묻는 질문, 커뮤니티 및 피드백

## 자주 묻는 질문

### Minecraft Bedrock 정품을 반드시 소유해야 하나요?

네. LeviLauncher는 **정품 Minecraft Bedrock Edition (GDK / UWP)** 와 함께 사용하도록 설계되었습니다.

### macOS 또는 Linux에서 사용할 수 있나요?

LeviLauncher에는 **Windows 버전**과 **Android 버전**([Android 가이드](/ko-KR/guide/version-management?platform=android))이 있습니다. macOS 및 Linux 버전은 없습니다.

### iOS 버전이 있나요?

아니요. iOS용 LeviLauncher는 제작할 계획이 없습니다.

### Release와 Preview 중 무엇을 선택해야 하나요?

평소 플레이할 때는 Minecraft **정식판(Release)** 을 우선 선택하세요. 앞으로 추가될 콘텐츠를 미리 체험해야 하고 불안정함을 감수할 수 있을 때만 **프리뷰판(Preview)** 을 고려하세요.

### 격리는 필수인가요?

필수는 아니지만, 테스트, Minecraft 프리뷰(Preview) 환경, 모드 환경에서는 강력히 권장합니다. 격리는 GDK 버전과 1.19.70.2 이상의 UWP x64 버전에서 사용할 수 있습니다.

### 런처 내에서 월드와 리소스 팩을 관리할 수 있나요?

네. LeviLauncher는 월드, 리소스 팩, 행동 팩, 스킨 팩, 스크린샷, 서버 목록 등의 콘텐츠 뷰를 제공합니다.

### 모드를 설치할 수 있나요?

가능하지만 고급 작업에 해당합니다. 깨끗하게 격리된 버전에서 시작해 단계적으로 테스트하는 것을 권장합니다.

### 명령줄에서 LeviLauncher를 사용할 수 있나요?

네, Windows 버전에서 사용할 수 있습니다. 인수 없이 `LeviLauncher.exe`를 실행하면 창이 열리고, `install latest`, `play`, `instance list`, `mod install <모드>` 같은 명령을 붙이면 터미널에서 실행된 뒤 종료됩니다. 전체 명령 목록은 `LeviLauncher.exe help`로, 각 명령의 옵션과 예시는 `LeviLauncher.exe help <명령>`으로 확인하세요.

### Android 버전에는 무엇이 필요한가요?

Android 9.0 이상이 설치된 ARM64 기기와 Google Play에서 설치한 Minecraft Bedrock Edition 1.21.80 이상이 필요합니다. 자세한 내용은 [설치](../install?platform=android)를 참고하세요.

### Android에서 여러 Minecraft 버전을 실행할 수 있나요?

네. 공식 Minecraft APK를 가져오면 런처 안에서 여러 버전을 실행할 수 있으며, 버전 격리로 데이터를 분리할 수 있습니다.

## 문제 및 기능 요청을 피드백하는 방법

다음 사항은 [GitHub Issues](https://github.com/LiteLDev/LeviLauncher/issues)로 제보해 주세요:

- 재현 가능한 버그
- 명백히 LeviLauncher와 관련된 설치 문제
- 모호한 문서 표현에 대한 개선 제안
- 사용 시나리오가 명확한 기능 요청

Android 버전 문제는 [LiteLDev/LeviLauncher-Android Issues](https://github.com/LiteLDev/LeviLauncher-Android/issues)에 등록하세요.

## Issue를 제출하기 전에 먼저 수행할 사항

- 사용 가능한 최신 버전으로 업데이트
- 깨끗하게 격리된 버전으로 비교 테스트 수행
- 새로 추가한 모드나 리소스 팩을 일시적으로 비활성화
- 문제가 발생하는 정확한 단계를 기록
