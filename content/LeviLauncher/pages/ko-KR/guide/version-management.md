# 버전 관리

LeviLauncher는 설치된 각 환경을 독립적으로 관리할 수 있는 버전으로 다룹니다. 앱에서는 설치된 버전을 인스턴스라고 부르며, **인스턴스** 페이지에 표시됩니다.

## 무엇을 할 수 있나요?

=== "Windows"

    - 정식판 또는 프리뷰판 설치
    - 알아보기 쉬운 버전 이름 설정
    - 원하는 버전을 빠르게 실행
    - 더 이상 필요 없는 버전 삭제
    - 버전 전용 설정 열기
    - 버전별 바탕 화면 바로가기 생성

=== "Android"

    - 공식 Minecraft APK를 가져와 시스템에 설치하지 않고 런처 안에서 각 버전 실행
    - 여러 버전과 각 버전의 데이터를 분리해 유지
    - 실행 화면에서 시작할 버전 선택

## 정식판(Release)과 프리뷰판(Preview)의 차이점 <Badge platform="windows" />

| 유형 | 적합 대상 | 설명 |
| --- | --- | --- |
| Release(정식판) | 안정적인 일상 플레이 | 대부분의 플레이어에게 적합 |
| Preview(프리뷰판) | 새로운 콘텐츠 사전 테스트 | 월드, 팩 또는 모드 호환성이 더 자주 바뀔 수 있음 |

## 격리란 무엇인가요?

=== "Windows"

    격리는 GDK 버전과 1.19.70.2 이상의 UWP x64 버전에서 사용할 수 있습니다. 격리를 켜면 LeviLauncher는 해당 버전의 게임 데이터를 기본 데이터 위치와 공유하지 않고 자체 작업 영역에 따로 저장합니다.

    격리는 다음과 같은 경우에 유용합니다.

    - 버전마다 서로 다른 콘텐츠 조합을 사용할 때
    - 모드 또는 Minecraft 프리뷰(Preview)를 더 안전하게 테스트할 때
    - 한 환경이 다른 환경에 영향을 줄 위험을 줄이고 싶을 때

=== "Android"

    가져온 버전의 월드, 팩, 설정을 Google Play에서 설치한 버전과 분리하려면 해당 버전의 버전 격리를 켜세요. 가져온 버전은 격리를 켜야 실행되는 경우가 많습니다.

## 일반적인 버전 작업 <Badge platform="windows" />

### 새 버전 설치

**다운로드** 페이지에서 설치를 마친 뒤 **실행** 페이지로 돌아갑니다.

설치 페이지의 **LeviLamina 설치** 스위치는 기본적으로 켜져 있습니다. LeviLamina 없이 게임을 설치하려면 이 스위치를 끄세요. 이 스위치는 LeviLamina가 지원하는 버전에만 적용됩니다.

### 버전 이름 변경

**인스턴스** 또는 **인스턴스 설정**에서 용도를 알아보기 쉬운 이름(예: `Release Survival` 또는 `Preview Test`)으로 변경합니다.

### 버전 삭제

더 이상 필요 없는 버전, 특히 테스트가 끝난 Minecraft 프리뷰(Preview) 환경을 삭제합니다.

::: warning 삭제 전에 먼저 확인하세요
버전을 삭제하면 해당 환경에 속한 관련 콘텐츠도 함께 삭제될 수 있습니다. 중요한 월드는 먼저 백업하세요.
:::

### 데스크톱 바로가기 생성

**실행** 버튼 옆 메뉴에서 **바탕 화면 바로 가기 만들기**를 선택하면 특정 버전을 바로 실행할 수 있는 바로가기를 만들 수 있습니다.

## 권장 버전 전략 <Badge platform="windows" />

- 일상 플레이용으로 격리된 정식판(Release) 버전 하나
- 필요할 때만 쓰는 격리된 프리뷰판(Preview) 버전 하나
- 모드 테스트나 문제 해결을 위한 임시 테스트 버전 하나
