# 다운로드 및 미러

LeviLauncher는 미러 선택, 작업 진행률 확인, 로컬 패키지 가져오기 기능을 제공하여 더 안정적으로 설치를 마칠 수 있도록 돕습니다.

## 이 영역은 무엇을 위한 것인가요?

- 설치할 수 있는 버전 찾아보기
- 속도 측정 또는 미러 소스 전환
- 다운로드 및 설치 진행률 확인
- 실패한 작업을 간편하게 재시도
- 필요한 경우 로컬 설치 패키지 가져오기

## 권장 작업 흐름

1. **다운로드**를 엽니다.
2. 설치할 Minecraft **릴리스** 또는 **미리보기**를 선택합니다.
3. LeviLauncher가 자동으로 속도를 측정하게 두거나, 직접 알맞은 미러를 선택합니다.
4. 설치 작업을 시작합니다.
5. 진행률을 더 자세히 보려면 작업 또는 다운로드 관리 화면으로 이동합니다.

## 언제 미러를 전환해야 하나요?

다음과 같은 경우에는 소스를 바꾸는 것이 좋습니다:

- 다운로드 속도가 눈에 띄게 비정상적일 때
- 특정 미러에 연달아 연결하지 못할 때
- 현재 소스에서 작업이 오랫동안 멈춰 있고 다른 소스가 더 안정적일 때

## 로컬 패키지 가져오기

호환되는 로컬 설치 패키지나 소스가 이미 있다면, LeviLauncher에서 이를 지원하는 과정에 로컬 가져오기 기능을 사용할 수 있습니다.

이 기능은 다음과 같은 상황에서 특히 유용합니다:

- 네트워크가 불안정할 때
- 이전에 다운로드해 둔 리소스를 다시 쓰고 싶을 때
- 직접 관리할 수 있는 고정된 설치 소스가 필요할 때

## 작업이 실패하면

다시 시도하기 전에 다음 항목을 확인하세요:

- 디스크 공간이 충분한지
- 대상 경로에 쓰기 권한이 있는지
- 필요한 Windows 구성 요소가 설치되어 있는지
- 현재 선택한 미러를 계속 사용할 수 있는지

문제가 계속되면 [업데이트 및 문제 해결](./update-troubleshooting)을 참고하세요.
