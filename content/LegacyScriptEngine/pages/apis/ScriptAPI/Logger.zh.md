# 📅 日志 API

> 这里提供了大量的 **辅助功能** ，包括日志功能、加载器功能接口等等。

它们让你能够更轻松自然地开发脚本，免去了处理无谓细节的麻烦。

## 📅 通用日志 API

以往，按指定格式将日志输出到特定位置非常麻烦。  
如今，脚本引擎提供了便捷的通用日志接口。

### 概念：关于日志输出等级

为了区分日志的优先级和重要程度，我们引入了 **日志输出等级** 的概念。  
日志输出等级越高，日志内容越详细，输出的日志量也越大。  
详见下表：

| 日志输出等级 | 对应等级名称 | 实际输出日志内容                |
|--------|--------|-------------------------|
| 0      | Slient | 不输出任何日志                 |
| 1      | Fatal  | 仅输出 严重错误信息              |
| 2      | Error  | 输出 严重错误、错误信息            |
| 3      | Warn   | 输出 严重错误、错误、警告信息         |
| 4      | Info   | 输出 严重错误、错误、警告、提示信息      |
| 5      | Debug  | 输出 严重错误、错误、警告、提示 和 调试信息 |

设置 **日志输出等级** 可以方便地过滤掉生产环境中无需输出的信息。

日志输出等级的默认值为`4`，即输出除调试信息以外的所有日志。  
你可以通过下面的 API 将日志输出等级调整为所需的值。

### 设置输出配置

使用通用日志接口之前，请先根据需求修改日志输出的相关配置。

通过修改设置，你可以自由选择将日志发送到控制台、文件甚至某个玩家。  
这些设置可以同时生效，例如可以设置同时发送到控制台和文件。  
如果不修改任何设置，**默认情况** 下，日志仅会输出到控制台。

#### 设置日志是否输出到控制台

`logger.setConsole(isOpen[,logLevel])`

- 参数：
    - isOpen : `Boolean`  
      设置日志是否输出到控制台。  
      开关默认处于打开状态。
    - logLevel : `Integer`  
      （可选参数）控制台的日志输出等级，默认为`4`。
- 返回值：无

#### 设置日志是否输出到文件

`logger.setFile(filepath[,logLevel])`

- 参数：
    - filepath : `String`  
      设置日志输出的目标文件路径。  
      传入空字符串或`Null`将关闭向文件的输出。  
      开关默认处于关闭状态。
    - logLevel : `Integer`  
      （可选参数）文件的最小日志输出等级，默认为`4`。
- 返回值：无

如果需要输出到文件，建议将日志统一输出到`BDS根目录/logs/`文件夹下，以便整理和检查。

#### 设置日志是否输出到某个玩家

`logger.setPlayer(player[,logLevel])`

- 参数：
    - player : `Player`  
      设置接收日志的目标玩家对象。  
      传入`Null`将关闭向玩家的输出。  
      开关默认处于关闭状态。
    - logLevel : `Integer`  
      （可选参数）玩家的最小日志输出等级，默认为`4`。
- 返回值：无

该功能专为方便游戏内调试而设计。输出给玩家的日志会作为聊天消息显示在目标玩家的屏幕上。

### 输出日志函数

完成设置后，即可使用以下函数输出日志：

`logger.log(data1,data2,...)` -> 输出普通文本  
`logger.debug(data1,data2,...)` -> 输出调试信息  
`logger.info(data1,data2,...)`  -> 输出提示信息  
`logger.warn(data1,data2,...)`  -> 输出警告信息  
`logger.error(data1,data2,...)`  -> 输出错误信息  
`logger.fatal(data1,data2,...)`  -> 输出严重错误信息

- 参数：
    - 待输出的变量或数据。  
      支持任意类型和任意数量的参数。
- 返回值：无

其中，**普通文本**会按原样输出，而其他输出接口会在日志内容前附加上**当前时间和日志类型**。  
例如，调用`logger.error("Fail to transport the player")`  
输出的日志结果为：

```log
[2021-05-21 19:41:03 Error] Fail to transport the player
```

### 其他的一些设置项

此外，还有一些其他设置项可用于更改日志的输出格式。

#### 设置自定义日志消息标头

`logger.setTitle(title)`

- 参数：
    - title : `String`  
      设置的自定义标头。
- 返回值：无

「标头」是日志条目开头的文字，用于直观地区分日志的输出源。  
默认情况下，标头为插件名称：LSE 会为每个插件创建一个以插件名称命名的日志记录器。

例如，调用`logger.setTitle("LeviLamina")`设置自定义标头后，  
接下来的日志输出格式将变为：

```log
20:05:26 ERROR [LeviLamina] Fail to transport the player
```

#### 统一修改日志输出等级

`logger.setLogLevel(level)`

- 参数：
    - level : `Integer`  
      日志输出等级。
- 返回值：无

统一重设所有输出方向的日志输出等级。
