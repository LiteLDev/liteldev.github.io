# 🔔 事件监听 API

> 事件系统让插件可以 **响应** 特定的游戏事件，让你可以在特定事件发生时执行代码。

以下 API 用于监听**游戏事件**并做出响应。

## 🔔 监听 API

注册指定的监听函数。  
当游戏中发生某种事件时，引擎会调用你设置的对应监听函数，以便你处理相关事件。  

### 注册监听器  

`mc.listen(event,callback)`

- 参数：

  - event : `String`  
    要监听的事件名（见下方监听事件列表）

  - callback : `Function`  
    注册的监听函数（函数相关参数见下文）  
    当指定的事件发生时，BDS 会调用你提供的监听函数，并传入相应的参数
- 返回值：是否成功监听事件
- 返回值类型：`Boolean` 



### 拦截事件

在脚本引擎的事件监听系统中，通常可以通过返回`false`来拦截某个可拦截的事件。拦截事件意味着在脚本拦截之后，BDS 将不再处理该事件，就像它从未发生过一样。  
举例：拦截某条聊天事件，会导致所有人都看不到这条聊天消息。

不过，拦截事件仅对 BDS 有效。  
也就是说，拦截事件不会影响其他同样监听了该事件的脚本引擎脚本处理这个事件，只是 BDS 无法再接收到它。



### 避开误区

有时，在某些事件监听内部调用特定的 API 会造成死循环崩服，请务必避免这种情况。  
举例：在`onConsoleCmd`事件监听中调用`mc.runcmd(Ex)`系列函数执行后台指令，将导致死循环。

## 📜 监听事件列表

侧边栏列出了脚本引擎支持监听的各种事件。

提示：你可以通过监听得到的游戏对象来获取其相关信息，例如方块的坐标、实体的名字等。  
同时，这些对象的成员函数也都可以直接调用。

> 注意！传入的回调参数中，有些参数有时可能为 Null，编写代码时请做好判空检查。
