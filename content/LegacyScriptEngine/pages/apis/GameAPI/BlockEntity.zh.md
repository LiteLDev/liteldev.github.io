# 📮 方块实体对象 API

脚本引擎通过「方块实体对象」来获取和操作特定方块的附加数据。  
注意：**方块实体对象** 不是 **实体**，两者之间没有特定关联。

### 获取一个方块实体对象

#### 通过方块获取


对于已存在的方块对象`bl`，可调用以下方法：

`bl.getBlockEntity()` 

- 返回值：该方块对象对应的方块实体对象 
- 返回值类型：`BlockEntity`
  - 若返回 `Null`，则表示获取失败，或者该方块**没有**对应的方块实体对象

> 注意：请勿**长期保存**方块实体对象。  
> 当方块被销毁时，对应的方块实体对象会随之释放。如需长期操作某个方块实体，请通过上述方法实时获取。




### 方块实体对象 - 属性

每个方块实体对象都包含一些固定的对象属性。特定方块实体对象`be`具有以下属性：

| 属性    | 含义                                               | 类型      |
| ------- | -------------------------------------------------- | --------- |
| be.name | The block entity name (example: `container.chest`) | `String`  |
| be.pos  | 方块实体对应方块所在的坐标                         | `IntPos`  |
| be.type | 方块实体对象的类型ID                               | `Integer` |

以上属性均为只读，不可修改。



### 方块实体对象 - 函数

每个方块实体对象都包含可调用的成员函数（成员方法）。对于特定方块实体对象`be`，可通过以下函数进行操作：

#### 获取方块实体对应的NBT对象

`be.getNbt()`

- 返回值：方块实体的NBT对象
- 返回值类型：`NbtCompound`



#### 写入方块实体对应的NBT对象

`be.setNbt(nbt)`

- 参数：
  - nbt : `NbtCompound`  
    NBT对象
- 返回值：是否成功写入
- 返回值类型：`Boolean`

有关NBT对象的更多用法，请参考 [NBT接口文档](../NbtAPI/NBT.zh.md)。



#### 获取方块实体对应的方块对象

`be.getBlock()`

- 返回值：方块实体对应的方块对象
- 返回值类型：`Block`

#### 设置方块实体自定义名称

!!! warning
    此函数仅在0.19.1及更高版本中可用。

`be.setCustomName(name)`

- 参数：
  - name : `String`
    新的方块实体自定义名称
- 返回值：是否设置成功
- 返回值类型：`Boolean`

#### 获取方块实体自定义名称

!!! warning
    此函数仅在0.19.1及更高版本中可用。

`be.getCustomName()`

- 返回值：方块实体自定义名称
- 返回值类型：`String`
